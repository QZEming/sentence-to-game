# 松果节拍 · Pinebeat

一个可直接在现代浏览器中游玩的 3D 森林节奏游戏。原生 JavaScript + Three.js，Web Audio 合成原创音乐，无构建步骤。

## 本地运行

```sh
npm start
```

打开 http://localhost:4173 。如端口被占用，可执行 `python3 -m http.server 8000 --bind 127.0.0.1 --directory dist` 并打开 http://localhost:8000 。不能直接双击 HTML：浏览器 ES 模块需要通过 HTTP 加载。

## 玩法

- ← / → 或 A / D：换道。
- 空格 / ↑ / W：踩拍收集松果，同时跳过树根。
- ↓ / S：下蹲躲过树枝，也可以换道避障。
- E：满能量后释放 8 拍森林爆发，自动收集并双倍计分。
- Esc / P：暂停；切到后台会自动暂停。
- 手机提供左右、跳跃、下蹲和爆发按钮，场景也支持滑动手势。

三档难度为 100 / 120 / 140 BPM。每局 192 拍，经过晨光松林、金色枫谷、萤火星夜。Perfect 100 分，Good 60 分，每 10 连击提升倍率，上限 ×4；爆发可叠加到 ×8。紫色松果提供 8 拍跨道收集，金色松果抵挡一次碰撞。漏拍不扣血，3 颗生命用尽会进入练习模式，依然可到达终点。最佳成绩和音量、延迟补偿等设置只保存在当前浏览器。

## 实现与验证

- `dist/engine.js`：谱面、节拍判定、连击、生命、道具和结算逻辑。
- `dist/music.js`：Web Audio 音序器、旋律、鼓点、音效。
- `dist/game.js`：3D 场景、松鼠角色、键盘触屏操作、HUD 和游戏状态。
- `dist/style.css`：桌面与移动端界面。
- `npm run check`：JavaScript 语法检查。

三档谱面已验证可全 Perfect；爆发卡顿补算及到期边界已验证。实际浏览器已验证开始、换道、踩拍计分、暂停恢复和移动端操作；140 BPM 完整一局验证 115 / 115 Perfect、115 连击、58,600 分，并正确展示终点结算，浏览器运行错误为零。第三方依赖 Three.js 为 MIT 许可，完整许可证见 `dist/vendor/THREE-LICENSE.txt`。
