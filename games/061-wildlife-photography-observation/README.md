# WILDFRAME 野境

可直接在浏览器运行的 Three.js 3D 野生动物摄影观察游戏。无需 API 密钥或后端。

## 本地运行

```sh
cd dist
python3 -m http.server 4187 --bind 127.0.0.1
```

打开 http://127.0.0.1:4187 。不能用 file:// 直接打开，因为浏览器需要通过 HTTP 加载 ES modules。

## 玩法

- WASD / 方向键：移动；鼠标或触摸拖动：环顾。
- C：蹲伏，降低脚步声、提高稳定度。
- T：等待，以 4 倍速度观察动物行为；移动自动结束等待。
- F：相机取景网格；滚轮 / 滑杆：35–200 mm 变焦。
- 空格或快门按钮：拍摄；J：打开相册。
- Shift：快走，会惊动近处动物。
- 手机支持方向按键、拖动环顾及独立拍摄按钮。

场景有汤氏瞪羚、草原象、平原斑马、长颈鹿和白鹭，共 16 只动物；每种有三种循环行为以及警戒反应。安静观察可积累耐心。水塘不可穿越，可绕行寻找角度。

照片按清晰度、主体表现、构图、行为时机和稳定度评分。评分检查模型投影边界、实体遮挡、快门速度和移动状态。今日计划包含首次有效记录、特别行为与三个物种记录，完成后授予探索徽章。

相册最多保留 24 张，数据仅存储于当前浏览器 localStorage，可筛选、查看评分、删除和下载 JPEG。第 25 张替换最早作品；存储失败会提示下载。其他浏览器和设备之间不自动同步。

帮助中可以切换薄雾清晨 / 金色黄昏、流畅画质、自然音效或返回观察点。3D 动物为程序化风格化模型，行为为游戏模拟。

## 技术与验证

- Three.js 0.180.0 已包含在 `dist/vendor`，许可证同步提供。
- 静态 HTML/CSS/ES modules，无构建步骤。
- 使用 `node --check dist/game.js` 检查 JavaScript 语法。
- 已用 Chrome / Playwright 检查场景加载、快门、蹲伏、等待、相册持久化与响应式布局。
- 浏览器 WebMCP 支持时暴露读取观察状态和调整焦距工具；未支持时自动跳过，不影响游戏。
