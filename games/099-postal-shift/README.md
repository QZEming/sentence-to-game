# 准点邮局 · Parcel Shift

中文 3D 邮局分拣反应游戏。静态网页，无构建步骤，无远程运行依赖。Three.js 0.170.0 已包含在 `dist/vendor`，许可证随库保存。

## 本地运行

```sh
python3 -m http.server 4868 --directory dist
```

打开 `http://localhost:4868`。需要支持 WebGL 的现代浏览器；若 WebGL 初始化失败，界面保留分拣操作。

## 玩法

- A / S / D / F：东城 / 南城 / 西城 / 北城；可点击路线卡片或场景中的邮箱。
- Q：加固易碎件；E：扫描模糊地址、核验超重包裹；R：退回寄件人。
- 退件优先于其余标签，组合特殊标签必须全部处理。
- 空格 / Esc：暂停；切换后台自动暂停。
- 班次挑战：早、午、晚三班，正确分拣目标为 10、14、18 件。完成班次获得邮币，可以升级传送带、得分印章和连击保险。
- 无尽高峰：每处理 12 件提升一次难度。轻松练习：无时限、无限信誉。
- 最佳分数与音效偏好只保存在当前浏览器，不需要账号。

## 验证

```sh
node tests/core.test.mjs
```

12 项规则检查涵盖路线唯一性、退件优先级、特殊处理、重复操作、计时、暂停、升级、保险和三班全通。`tests/browser-check.mjs` 使用本环境的 Playwright 与 Chrome，验证实际点击、键盘、WebGL、升级和移动端溢出。

`document.modelContext` 可用时，页面注册读取状态、开始游戏和处理包裹三个 WebMCP 工具；当前 Chrome 不支持该接口，真实浏览器注册验证不可用。普通游戏操作不依赖此接口。
