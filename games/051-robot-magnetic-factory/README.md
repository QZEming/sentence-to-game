# MAGNET WORKS · 磁力工坊

基于 Three.js 与 Cannon-es 的 3D 工厂磁力搬运解谜游戏。所有模型、标识、光照及场景均由代码生成。

## 运行

```sh
npm install
npm run dev -- --port 5278
```

浏览器访问 http://127.0.0.1:5278 。生产构建使用 `npm run build`，产物位于 `dist/`。

## 操作与目标

- WASD / 方向键移动，或点击地面指定目的地。
- E 开启磁力、吸附最近货箱，或释放货物；也可点击底部磁力模块。
- Q 切换吸引与排斥，也可点击底部模式按钮。
- 空格释放磁力脉冲，消耗 25% 能量；也可点击右侧 ✦。
- R 重置当前关卡；Esc 暂停；右侧 ⟳ 旋转视角。
- 货箱进入同色装卸区后，释放磁力并等待稳定，即可入库。

五关依次包含基本搬运、压力开关与闸门、传送带、重型货箱与危险区、综合挑战。灰箱为机关辅助物，无需入库。误入危险区的货箱自动回到起点。关闭磁力可自动充能。成绩保存于浏览器 localStorage，100 秒内且少于 18 次磁力操作可得三星。

## 技术与验证

- 固定步长刚体物理，碰撞、惯性、摩擦、带阻尼的磁力伺服和冲量。
- 支持桌面与窄屏，音效可开关，关卡可以直接选择。
- `npm run build` 验证生产构建。
- `output/playwright/check.mjs` 是本地浏览器交互检查脚本，使用已安装的 macOS Chrome，验证移动、极性、脉冲、切关、暂停和截图。运行前启动 5278 端口的开发服务器。
- `output/playwright/movement.mjs` 验证持续移动的物理位移。
- `output/playwright/delivery.mjs` 通过点击地面与键盘操作，验证吸附、搬运、释放及完整关卡入库流程。

目前为单机游戏；进度保存在当前浏览器，不包含服务端或账号系统。
