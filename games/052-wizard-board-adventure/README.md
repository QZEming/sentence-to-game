# 星棋秘境 · Astral Gambit

可直接游玩的中文 3D 回合制巫师战棋游戏。静态应用，Three.js 已随项目附带，无需安装依赖。

## 本地运行

```sh
npm start
```

打开 `http://127.0.0.1:43125`。也可将 `dist` 作为静态目录部署。

## 玩法

- 三幕 8×8 棋盘：微光林地、余烬废墟、星蚀王座。
- 每回合 3 行动点，结束回合回复 2 法力。
- 移动，以及奥术飞弹、陨火术、霜缚、闪现、星光护盾、冥想六种法术。
- 四类敌人、寻路、攻击视线、冻结与免疫、范围预警首领机制。
- 经过宝箱或月泉自动拾取；在星隙上结束回合受到伤害。
- 每幕结束三选一遗物，共六件，影响生命、法力、伤害、防御与移动。
- 本机自动存档、故事/标准难度、音效、视角旋转缩放、坐标网格、响应式布局。

鼠标点击移动/施法，拖动旋转，滚轮缩放；1–7 选行动，Space 结束回合，Q/E 旋转，R 重置视角，Esc 取消选择。

## 检查

```sh
npm test
```

14 项规则回归测试覆盖资源扣除、路径拾取、视线/目标边界、冻结、绕障、回合锁、护盾、危险地形、首领预警、遗物与胜利、存档往返。

已通过桌面和手机布局实测，以及施法、击杀、敌方回合、资源恢复的浏览器交互检查。WebMCP 在支持 `document.modelContext` 的浏览器中注册战局读取和行动工具；当前验证浏览器不提供该标准的可调用测试界面，未验证真实 WebMCP 调用。

## 技术与授权

`dist/engine.js`：独立规则引擎。`dist/scene.js`：Three.js 场景。`dist/app.js`：界面、存档与交互。

Three.js r170 使用 MIT 许可证，见 `dist/vendor/THREE-LICENSE.txt`。游戏几何、界面与音效均由代码生成。字体有系统回退，3D 运行需要 WebGL 支持。

存档仅保存在当前浏览器的 localStorage，不跨设备同步。星尘作为冒险得分记录，不涉及充值或真实货币。
