# ORBIT RUNNER · 轨道漫游者

一个无需外部美术资源的 Three.js 3D 跑酷游戏。小机器人 R-07 在废弃空间站收集三枚反应堆核心，穿越停泊港、反应堆长廊与失重遗迹，启动逃生舱。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端打印的本地地址。生产构建：`npm run build`，预览构建：`npm run preview`。静态产物位于 `dist/`。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 跳跃、空中二段跳 | 空格 |
| 冲刺 | Shift，约 1 秒冷却 |
| 加速奔跑 | Ctrl 按住 |
| EMP 能量脉冲 | E，令 13 米内机关失效约 3 秒，6 秒冷却 |
| 回到检查点 | R |
| 暂停 / 继续 | Esc / P |
| 静音 | M |
| 转动镜头 / 缩放 | 拖动画面 / 滚轮 |

触屏设备显示方向键、跳跃、冲刺和脉冲按钮。可在设置中切换画质。

## 玩法

- 18 座平台，包含横移平台和一条弹射支路。
- 3 个区域、3 枚核心、能量晶体与 3 份可探索的日志。
- 周期激光、落下的压机与可以暂时干扰机关的 EMP。
- 低重力区延长腾空时间，支持空中转向、二段跳和冲刺组合。
- 检查点自动保存，失败保留收集成果；到达检查点恢复装甲。
- 探索和计时挑战两种模式，挑战每次复活追加 5 秒。
- 每收集 10 个晶体修复一格装甲；本地保存各模式最佳通关时间和静音偏好。
- 程序化机器人动画、粒子、泛光、动态阴影与 Web Audio 音效。

## 验证

```bash
npm test
npm run build
```

测试覆盖跳跃、碰撞、土狼时间、输入缓冲、移动平台跟随、冲刺冷却与低重力，并通过实际物理控制器模拟各主线平台连接及弹射支路。浏览器需支持 WebGL 2，建议使用桌面版 Chrome / Edge。

代码划分：`main.js` 游戏状态和交互；`physics.js` 物理；`world.js` 关卡；`robot.js` 角色；`ui.js` / `style.css` 界面；`audio.js` 音效；`particles.js` 粒子。
