# ORBIT ZERO — 最后一束信号

基于 Three.js 的第三人称 3D 太空站跑酷游戏。所有模型、场景、材质、粒子和音效均由代码生成。

## 启动

```sh
npm install --registry=https://registry.npmjs.org
npm run dev -- --host 127.0.0.1 --port 5187
```

打开 http://127.0.0.1:5187 。生产构建：`npm run build`，预览：`npm run preview`。

## 操作

- A / D、左右方向键：切换三条跑道
- Space / W / 上方向键：跳跃、二段跳
- Shift：离子冲刺，短暂无敌，3 秒冷却
- S / 下方向键：滑铲通过激光门
- Esc：暂停 / 继续
- 触屏：按钮或滑动操作

## 玩法

目标：携带信号穿过 2,400 米废弃空间站，重启通讯塔。

- 34 段平台、断桥、横移平台、货箱、激光门、移动无人机
- 外环、低重力反应堆、通讯塔三个区域，逐渐加速
- 96 枚能量晶体与收集连击，每收集 15 枚修复一格机体
- 蓝色护盾抵挡一次撞击；紫色磁场提供 10 秒跨跑道收集
- 二段跳喷焰、冲刺视野变化、碰撞粒子、合成音效
- 三格机体完整度、检查点、坠落回收、死亡重试、通关结算
- 本地保存最远距离；暂停、操作指南、静音、移动端按钮

不需要后端或账户。运行依赖通过 npm 安装；界面字体在线加载，无法联网时使用系统字体。
