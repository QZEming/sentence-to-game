# 梦境守护者 · Dreamkeeper

一个无构建依赖的中文 3D 空间记忆浏览器游戏。使用 Canvas 2D 对三维坐标进行透视投影，支持轨道旋转、纵向视角和缩放。背景为原创生成素材。

## 本地运行

在本目录运行：

```sh
python3 -m http.server 5287 --bind 127.0.0.1 --directory dist
```

打开 `http://127.0.0.1:5287`。所有游戏素材位于 `dist/`；Google Fonts 无法加载时使用系统字体。游戏无需服务器 API 或账号。

## 玩法

- 梦境之旅：八个星座关卡，观察后重建连线，三颗梦境之心。
- 自由观星：不限回忆时间，错误提交不扣生命。
- 无尽星河：循环星座并改变空间形状，增加干扰星，缩短观察时间。
- 星光回溯：每轮两次，显示星座两秒，同时暂停回忆计时。
- 凝结时光：每轮一次，增加十秒回忆时间。
- 正确连线、用时、提示和失误影响奖励；图鉴、星级和最佳成绩保存在当前设备的 localStorage。

点击两颗星连接，重复连接删除；点击当前选中的星取消选中，可从其他星绘制分支。空白处拖动旋转，滚轮缩放。

快捷键：Enter 开始或提交，Esc 暂停，H 回溯，T 延时，R 重置视角，Ctrl/Cmd+Z 撤销。方向键切换星辰，空格选择；1–9 可直接选择对应编号。

## 结构

- `dist/index.html`：语义界面、对话框和图标。
- `dist/style.css`：响应式主题和移动端布局。
- `dist/game-core.js`：星座数据、图判定、奖励和难度。
- `dist/game.js`：游戏状态、三维渲染、输入、音乐和设备存储。
- `dist/assets/night-sky.jpg`：原创星空背景。

游戏可选注册浏览器 WebMCP 工具：读取可见进度、开始观察、连接两颗星。浏览器不支持时不影响玩法；工具不会泄露隐藏答案。

## 验证

JavaScript 语法检查；24 个生成关卡的完整、缺失和多余连线判定；桌面和 390px 手机视口检查。完整浏览器流程另验证观察、暂停、回溯、延时、鼠标连线通关、下一关、模式切换、自由模式和本地进度保存。

`.openai/hosting.json` 指向此项目的私有 Sites 发布。
