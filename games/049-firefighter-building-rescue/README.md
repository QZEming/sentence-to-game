# 烈焰指挥 · FIRE COMMAND

使用 Three.js 构建的中文 3D 实时消防救援策略游戏。无需安装依赖。

## 运行

在此目录运行 `npm start`，浏览器打开 http://localhost:4173 。需要 Node.js 18+ 和支持 WebGL 的浏览器。

也可以运行 `python3 -m http.server 4173 --directory dist`。不要直接用 file:// 打开 index.html，浏览器会限制 ES 模块加载。

## 玩法

- 点击“开始行动”，可随时按空格进入战术暂停，暂停时仍能安排任务。
- 右侧选择小队（快捷键 1–6），点击大楼房间或左侧楼层格子，派遣当前行动。
- Q 灭火、W 搜救、E 排烟、R 加固、B 撤退补给。
- 火势达到 70% 会阻挡搜救；先灭火再进入。搜救成功奖励指挥点。
- 队员消耗氧气，处于强火中会受伤，氧气过低或重伤自动撤退。回到集结区自动恢复。
- 支援包括全楼水炮、持续供水、无人机疏散引导，以及最多两支增援队。
- 拖动画面旋转，滚轮缩放，底部按钮切换 1× / 2× / 3× 时间倍率。
- 三个行动场景：长夜公寓、风暴之眼、最后的曙光。完成救援并扑灭明火获得评分；楼体稳定度归零则行动失败。

## 文件

- `dist/index.html`：界面和入口
- `dist/style.css`：响应式指挥台
- `dist/app.mjs`：3D 场景、粒子、交互和界面
- `dist/engine.mjs`：独立、确定性随机的游戏模拟
- `dist/vendor/three.module.js`：本地 Three.js 0.170.0（MIT）
- `server.mjs`：零依赖本地服务器

游戏和场景无需网络；可选 Google Fonts 加载失败时使用系统字体。进度仅保留在当前页面，刷新会重开。场景为游戏化模拟，并非真实消防培训系统。
