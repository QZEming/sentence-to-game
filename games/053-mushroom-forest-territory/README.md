# MYCELIUM · 林间共生

Three.js 构建的 3D 回合制区域控制策略游戏。61 片六角领地、低多边形森林、可旋转视角、动态菌丝与孢子粒子。

## 运行

```sh
npm install --registry=https://registry.npmjs.org
npm run dev
```

生产构建：`npm run build`；预览：`npm run preview`。

## 操作

点击地块选择，拖动旋转、滚轮缩放。选择目标后点击行动，或按 1–4。空格结束回合。

- 菌丝蔓延：25 孢子连接相邻土地；敌方领地触发战斗。
- 孢子苗圃：40 孢子、10 露水，额外提供每回合 7 孢子。
- 菌盖守卫：35 孢子、15 露水，防御提升至 12。
- 生命绽放：30 露水，按领地数量立即收获孢子。
- 泉眼提供露水，古树提供高额收入和首次占领奖励。
- 每 4 回合雨季额外提供 20 露水，敌方自动扩张并进攻。
- 占领 31 片土地或夺取敌方母巢获胜；母巢失守则失败。

进度在有效行动后自动保存在当前浏览器；在「设置」中保存、读取或重新开始。

所有三维场景均由程序生成；游戏运行不依赖远程图片或模型。Google Fonts 加载失败时使用系统字体。
