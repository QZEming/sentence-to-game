# 萤途 · LUMEN

为迷路旅人规划光路的可玩 3D 森林解谜游戏。使用 Three.js + Vite，无后端。

## 运行

```sh
npm install --registry=https://registry.npmjs.org
npm run dev
```

打开终端输出的本地地址。`npm run build` 生成可部署的 `dist/`，`npm run preview` 预览构建结果。

## 玩法

- 从旅人所在格开始，点击上下左右相邻石块铺路；点击已有路径回退。
- 连通发光石门后，点击「跟随微光」或空格出发；空格也可暂停。
- 普通格消耗 1 光能，褐色湿地消耗 2 光能。
- 金色碎片提供通关评级：抵达 1 星，收集部分 2 星，收集全部 3 星。
- 蓝色月光石开启月门；紫色传送石可以直接连接另一端。
- 移动暗影挡路时，旅人在安全格自动等待。
- Z 撤回，R 重置，H 提示，Esc 关闭弹窗；拖动旋转，滚轮缩放。
- 六章自由选择，最高评级保存在当前浏览器 localStorage；音效默认关闭，可在右上角开启。

## 章节

1. 初见微光：铺路与收集
2. 苔间回声：湿地与光能管理
3. 月门低语：开关与封印
4. 星河两岸：双向传送
5. 暗影之舞：动态障碍与等待
6. 长夜归途：综合探索，多种路线

## 验证

- 生产构建通过。
- 六关均验证存在预算内的全碎片路线，耗能分别为 10/14、16/16、17/18、13/15、14/16、15/22。
- Chrome 实际棋盘点击、通关、下一关、章节选择、帮助及提示交互检查。
- 390px 手机布局无横向溢出。
- 截图与浏览器验证脚本位于 `output/playwright/`；脚本运行需要额外安装 Playwright，并安装 Chrome。

字体可使用 Google Fonts；无法联网时自动使用系统字体，不影响游戏。游戏需要支持 WebGL 的浏览器。
