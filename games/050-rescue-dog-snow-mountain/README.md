# 雪迹 ALPINE

Three.js 3D 嗅觉追踪搜救游戏。运行 `npm start`，访问 http://127.0.0.1:5191 。无需安装依赖，Three.js 已本地打包。

WASD / 方向键移动；Shift 奔跑；空格嗅闻；E 调查，按住 E 救援；M 展开地图；拖动旋转视角；滚轮缩放；Esc 暂停。移动端支持触屏操作。

三位登山者、十二个线索、三档难度、动态风向与暴风雪、体力体温、营地恢复、冰缝危险、可选环境音、雷达与救援评分。本地存储个人最佳得分。

`npm run check` 检查脚本语法。发布目录为 dist，全部核心游戏资源本地提供；在线字体失败时回退系统字体。
