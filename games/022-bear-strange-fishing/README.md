# 小熊奇鱼记 · Wonderlake

原生 ES Modules + 本地 Three.js 的 3D 湖畔钓鱼游戏，无需构建或安装依赖。

## 本地运行

```sh
npm run dev
```

打开 http://127.0.0.1:4876/ 。需要现代浏览器与 WebGL。所有游戏资源均保存在 `dist/`；在线字体不可用时自动使用系统字体。

## 玩法

- 按住操作按钮或空格蓄力，松开抛竿。55%–80% 是精准区域。
- 咬钩后 3 秒内点击起钩；按住收线，松手降低张力。张力 ≥95% 持续 1.1 秒会断线。
- 操作按钮获得键盘焦点时，Enter 可以切换按住/松手，无需持续按键。
- 3 个免费钓点、12 种奇异鱼、4 档稀有度；天气与时段只影响概率，不会锁死图鉴。
- 3 条装备升级路线，各有 3 级；3 个自动领奖任务；首次捕获与连续失败后提供辅助。
- 图鉴、金币、装备、任务、时段与钓点自动保存在当前浏览器的 localStorage。没有账号或云同步。
- C 图鉴、E 工坊、Esc 关闭面板/收线；拖动旋转、滚轮缩放；支持触屏。
- 工坊/图鉴等模态窗口与后台页面会暂停钓鱼。休息可以免费切换时段与天气。

## 源码

- `dist/scene.js`：3D 场景、小熊、鱼、水面、粒子、昼夜、雨景与相机。
- `dist/data.js`：鱼种、装备、任务、随机选鱼、搏鱼与存档清理。
- `dist/game.js`：输入、游戏状态、存档、界面、音效与只读 WebMCP 工具。
- `dist/style.css`：桌面与移动端布局。
- `dist/vendor/`：Three.js 与 MIT 许可证。

运行 `npm run check` 检查 JavaScript 语法。部署采用 `.openai/hosting.json` 的静态 `dist/` 目录。
