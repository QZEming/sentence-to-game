# 鲸落之境 · ABYSSAL

浏览器中的 3D 深海探索游戏。化身蓝鲸，唤醒三处遗迹，最终唱响深海之心的鲸歌。

## 运行

在本目录执行 `python3 -m http.server 4261 --bind 127.0.0.1 --directory dist`，然后打开 http://127.0.0.1:4261 。

无需安装依赖或构建；Three.js 已随源码附带。浏览器需要支持 WebGL 2。画面设置中可切换“流畅”模式。字体联网加载失败时自动使用系统字体。

## 操作

| 操作 | 按键 |
|---|---|
| 前后游动 / 左右转向 | W、S / A、D，或方向键 |
| 上浮 / 下潜 | Space / C（也支持左 Ctrl） |
| 冲刺 | Shift |
| 声呐 | E |
| 与遗迹共鸣 | F |
| 海图 / 日志 / 进化 | M / J / U |
| 暂停 | Esc |
| 转动镜头 / 缩放 | 拖动场景 / 滚轮 |

触屏设备提供摇杆、升降、声呐和互动按钮。

## 航程

- **回声庭院**：声呐揭示石壁线索，按正确顺序重奏三枚符文。
- **潮汐圣所**：旋转三个导流器，使洋流汇聚。
- **星陨之庭**：探索圆环周围，收集三枚独立任务星片并归还。
- **深海之心**：集齐三个印记后触发鲸歌结局；结局后继续自由探索。
- 35 枚回声晶石、6 种生命记录、3 类各两级能力进化。
- 气息管理、补给气泉、浅水恢复、水母危险与声呐驱散、洋流加速。
- 海图目标追踪与已访问遗迹快速传送。
- 浏览器本地自动存档，可继续上次航程；任务物品不用于消费。
- 打开面板暂停模拟；耗尽气息或手动返回安全点不丢进度。

存档保存在当前浏览器的 localStorage，不跨设备同步。开始新航程前会确认是否替换当前存档。

## 文件

- `dist/game.js`：状态、输入、谜题、进化、存档、音景和界面。
- `dist/world.js`：程序化海底、遗迹、环境生命与渲染。
- `dist/animals.js`：鲸鱼、水母、蝠鲼模型与骨架式分组动画。
- `dist/style.css` / `dist/index.html`：响应式游戏界面。
- `dist/vendor/`：Three.js 0.180.0（MIT，版权声明随附）。

所有场景和动物均为程序化建模，不依赖远程 3D 模型或图片资源。
