# 免疫指挥官 · MICROFRONT

使用 Three.js 实时渲染的中文免疫细胞即时战略游戏。静态文件位于 `dist/`，无需构建或安装依赖。

## 本地运行

```bash
python3 -m http.server 8080 --directory dist
```

打开 http://localhost:8080 。需要支持 WebGL 2 的现代浏览器。请通过 HTTP 打开，直接双击 HTML 的 file:// 模式不支持 ES 模块加载。

## 玩法

- 5 种细胞：巨噬细胞承伤、中性粒细胞溅射突击、杀伤 T 细胞抗病毒、B 细胞远程减速、辅助 T 细胞治疗与增益。
- 8 波进攻，4 类病原体，最终首领带蓄力预警和范围冲击。
- 3 个可争夺营养节点，招募队列、人口上限、击杀与波次奖励。
- 修复脉冲、炎症爆发、干扰素场 3 种定点技能。
- 细胞膜、抗原识别、代谢 3 条研究，每条 3 级。
- 休闲、标准、危机三档难度，暂停、两倍速、可选音效、重新开始。
- 桌面框选、Shift 追加、右键移动或集火、雷达定位、缩放、平移；手机点选后点地面移动，下方指挥卡片可横向滚动。

快捷键：1–5 招募；A 全选；H 驻守；R 回防；Q/W/E 技能；空格暂停；Enter 下一波；Esc 取消；方向键平移。

## 文件

- `dist/index.html`：界面与帮助对话框。
- `dist/style.css`：桌面及手机布局。
- `dist/simulation.js`：独立战斗、经济、研究、技能和波次规则。
- `dist/game.js`：3D 场景、单位模型、特效、输入、UI、WebMCP 可选适配。
- `dist/vendor/`：固定版本 Three.js 0.180.0 与 MIT 许可。

无账户、后端或付费 API。字体使用 Google Fonts，离线回退系统字体。浏览器仅在本机保存最佳战绩，刷新会重开战役。
