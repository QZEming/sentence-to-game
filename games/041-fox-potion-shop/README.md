# 狐尾炼金铺 / Foxglove Alchemy

无需构建的 Three.js 3D 炼金经营游戏。运行：

```sh
python3 -m http.server 4286 --directory dist
```

打开 http://localhost:4286 。需要支持 WebGL 的现代浏览器。

- 3D 低多边形森林小屋、可移动狐狸、动态炉火与蒸汽、可点击设施、滚轮缩放。
- 6 种材料、8 种配方、3 种火候、搅拌时机小游戏、失败研究补助。
- 每日采集、3 条探索路线与精力系统、3 种每日事件。
- 顾客订单、摆摊出售、金币、声望、3 类升级、5 项成就。
- 浏览器本机自动存档；桌面键盘与移动端按钮操作。
- WebMCP：读取游戏状态、打开游戏工作站。

## 验证

JavaScript 语法检查通过。浏览器中确认 3D 场景渲染；选择月露草和焰心莓，以温火合成治愈药剂，材料从 6/5 降为 5/4，成品 +1，声望 +2；交付订单后金币从 120 增为 215（45 订单 +50 首单奖励），声望增为 7，成品恢复为 0。

游戏存档仅存在当前浏览器，不提供云端同步。Three.js r170 已随源码打包；字体联网失败时使用系统后备字体。
