# Beaver Brook · 海狸造桥记

基于 Three.js 与 Vite 的完整 3D 森林建桥小游戏，无需图片或模型服务。

## 运行

```bash
npm install --registry=https://registry.npmjs.org
npm run dev
```

打开终端显示的本地地址。`npm run build` 生成 `dist/`；`npm run preview` 预览生产版本。

## 操作与玩法

- 点击树木或按 **1**：海狸自动走近采木。小树 12 秒后再生。
- 点击地面，或 **WASD / 方向键**：移动。未连通的河面不可通过。
- 按 **2 / 空格**：消耗木材搭建桥面；共需 6 段。受损时优先维修。
- 按 **3**：桥梁连通后召集兔子、狐狸、熊，逐一回家。
- 救援每位动物获得 5 橡果，完成章节额外获得 10 橡果。
- 两级工具升级提升木材采集量、移动速度与背包容量。
- 三个章节，每段桥的费用依次为 2 / 3 / 4 木材。
- 第二章起漂木会损坏桥面，使用 2 木材维修后动物才能继续。
- 滚轮或右下角按钮缩放；右上角开关音效、帮助、暂停。
- 完成三章可查看救援数量、橡果与用时，重新开始冒险。

包含程序化低多边形场景、实时阴影、水流动画、采集粒子、桥梁建造动画、动物行走、响应式界面和可选合成音效。无外部字体或 CDN 运行依赖。

## 验证

`npm run build` 验证生产构建。`output/playwright/smoke.mjs` 为浏览器交互验证脚本，使用本机 Chrome；执行前将其 URL 改为当前 Vite 端口。截图保存在同一目录。
