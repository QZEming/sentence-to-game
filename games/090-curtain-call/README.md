# 幕间 · Curtain Call

3D 剧院导演调度游戏。Three.js 实时舞台，纯静态网页，无后端、账户或 API 密钥。

## 游玩

打开已部署站点，或在本目录运行 `npm start`，访问 http://127.0.0.1:4319 。

- 点击演员卡或按 1–4 选择演员，再点击舞台地面安排走位。
- M：前往剧本标记点；空格：开演/暂停；R：消耗锦囊救场；?：操作指南。
- 拖动舞台旋转视角，滚轮缩放，可切换导演/观众/俯视视角。
- 按时间轴完成走位、灯光、音效任务。提示前 5 秒开放，标准模式允许延后 15 秒。
- 三幕共 15 条提示、6 次随机事件。8 类事件有稳妥或明确成功概率的即兴选项。
- 排练可跳幕、超时不扣满意度；正式演出有评分和连击。三种难度改变事故处理时间。
- 快跑消耗体力，静止恢复。锦囊每场 3 次，未出现事故时不会消耗。
- 亮度、追光、幕布、雾效、布景、三种合成音效均可控制。
- 演出档案保存在当前浏览器 localStorage，最多 20 场；不提供云同步。

## 技术与验证

`dist/` 包含完整可部署静态内容，Three.js 已随包提供，无需运行时从 CDN 获取脚本。字体来自 Google Fonts，网络不可达时使用系统字体。

- `npm run check`：JavaScript 语法检查。
- `npm test`：7 项游戏流程模拟，覆盖暂停、跨幕、事故期限、锦囊、完整三幕 S 级流程、重置和重复结算防护。

需要支持 WebGL 的现代浏览器。开发依赖使用 `npm ci --registry=https://registry.npmjs.org` 安装；普通本地运行只需要 Python 3。
