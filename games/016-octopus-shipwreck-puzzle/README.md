# 章鱼秘航 · OCTO VAULT

一个可直接在现代浏览器中游玩的 Three.js 3D 沉船解谜游戏。无后端、无需构建，Three.js 已随项目本地打包，游戏主体不依赖 CDN。

## 运行

```sh
python3 -m http.server 4187 --directory dist
```

打开 http://localhost:4187 。需要启用 WebGL 的浏览器。

## 操作与目标

- WASD / 方向键：游动；Shift：冲刺。
- 点击甲板：移动到目标；拖拽：旋转视角；滚轮：缩放。
- E：靠近机关或日志交互。
- Space：喷墨，附近水母失去方向 6 秒；冷却 8 秒。
- Q：声波，标出尚未收集的珍珠；冷却 12 秒。
- Esc：暂停；H 或右上角问号：帮助。
- 手机使用左下摇杆、右侧交互与能力按钮。

解开星象舵轮、回声贝壳和潮汐能源三个机关，开启船尾宝箱，唤醒潮汐之心。可选收集 18 颗珍珠及 3 页航海日志。伤害耗尽时返回安全点，保留所有进度。存档在浏览器 localStorage；暂停菜单可以重新开始。

## 文件

- `dist/world.js`：场景、动画角色、道具、水母、粒子效果。
- `dist/game.js`：控制、碰撞、收集、存档、海图、音效及主循环。
- `dist/puzzles.js`：三个谜题、帮助、日志、暂停及结局。
- `dist/style.css`：响应式游戏界面。
- `dist/lib/`：Three.js 0.180.0（MIT License）。

场景全部以 3D 几何体实时绘制。界面字体可选加载 Google Fonts，无法联网时自动使用系统字体。
