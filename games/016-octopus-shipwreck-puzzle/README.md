# ABYSSAL · 深海回响

一款 Three.js 实时 3D 沉船探索解谜游戏。所有场景模型均由代码生成，无需下载模型素材。

## 启动

```bash
npm install --registry=https://registry.npmjs.org
npm run dev
```

打开终端中的本地地址。`npm run build` 生成 `dist/`，可用 `npm run preview` 预览生产版本。

## 玩法

- WASD / 方向键：相对于画面游动；E：靠近机关或宝箱交互。
- 空格：喷墨冲刺，消耗 30 能量并暂时驱散海鳗。
- Q：声呐扫描，消耗 20 能量；能量自动恢复。
- Esc：关闭机关界面 / 暂停；右上角可开启音效、查看帮助或暂停。
- 三个机关可以任意顺序完成：潮汐阀门（水压谜题）、星象齿轮（天象排列）、回声石阵（五步旋律记忆）。
- 集齐三枚符印后打开右侧船长宝箱，找回海洋之心。
- 靠近八颗珍珠自动收集；全部收集可获得深海收藏家称号。
- 通关后可继续探索，或重新启航。移动端提供方向和交互按钮。

## 实现

Vite + Three.js；程序化沉船、帆索、货物、海床、珊瑚与海草；八腕章鱼、鱼群、水母和海鳗动画；实时阴影、雾效、发光机关、粒子与 Web Audio 音效。进度保存在当前游戏会话中，刷新会重新开始。
