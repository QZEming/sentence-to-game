# 观相 · PARALLAX

以观看角度、投影拼接、遮挡和尺度为核心的 3D 魔术解谜游戏。纯静态网站，Three.js 0.169.0 已随项目打包，不需要构建或外部 JavaScript CDN。

## 运行

在本目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

打开 `http://127.0.0.1:8765`。需要支持 WebGL 的现代浏览器。中文字体使用 Google Fonts，字体不可用时自动回退到系统字体。

## 六幕谜题

1. 掌中星辰：缩放水晶，使其填满目标线框。
2. 破碎的圆：旋转视角，让不同深度的弧线投影闭合。
3. 藏月礼帽：寻找能完整遮住月亮的观察角度。
4. 不可能之桥：调整中段尺度和观察角度，连接悬空阶梯。
5. 镜外之门：让位于不同深度的两扇门框重合。
6. 最后的奇迹：同时完成星环拼接与月亮尺度匹配。

## 操作

- 鼠标或单指拖动：环绕与俯仰观察。
- 滚轮、Q / E 或滑杆：改变可控道具尺度。
- 方向键：微调视角；按住 Shift 更慢地调整。
- 空格：共鸣达到 94% 后施展魔术。
- H：逐级提示；V：魔术透镜；R：重新开始当前关卡。
- 顶部菜单：章节选择、声音、完整操作说明。

关卡、最佳成绩、星级与声音偏好保存在当前设备的 localStorage。每幕三颗星：完成、未使用提示、90 秒内完成。没有账号、服务器或个人数据收集。

## 验证

```sh
node --check dist/game.js
node --no-warnings verify-puzzles.mjs
```

`verify-puzzles.mjs` 使用同一份实际游戏逻辑，检查每幕初始状态未完成、预设解可达到 100% 共鸣。浏览器检查覆盖桌面与手机布局，以及真实输入、结算和章节解锁。测试截图保存在本地 `output/playwright/`（不参与部署）。

## 文件

- `dist/index.html`：游戏界面和弹窗。
- `dist/style.css`：响应式剧场界面。
- `dist/game.js`：3D 场景、谜题、输入、音效、存档。
- `dist/vendor/`：Three.js 和 MIT 许可证。
- `.openai/hosting.json`：Sites 静态托管配置。

本项目的演出时间、星级和存档均为设备本地状态，不在设备之间同步。
