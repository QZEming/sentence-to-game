# 重启乐园 · Park Revival

一个使用 Three.js 构建的可直接游玩的 3D 清洁修复游戏。无服务器游戏逻辑，游戏引擎已随项目保存，进度仅存于当前浏览器。

## 本地运行

```sh
python3 -m http.server 4867 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4867/ 。需要支持 WebGL 的现代浏览器。

## 玩法

- 五个设施：旋转木马、日落摩天轮、冒险海盗船、时光售票亭、许愿喷泉。
- 鼠标左键持续冲洗，右键拖动旋转，滚轮缩放；点击设施清单快速前往。
- 1/2/3 切换标准喷头、广角喷头、清洁刷。广角喷头可清洗附近未遮挡的部件；清洁刷不耗水。
- R 免费补水；F 高亮未清洁部件；E 修复已清洁至少 95% 的当前设施。
- 每个部件清洁完成奖励 3 修复币。设施维护包含三个步骤，完成后获得金币并启动对应动画。
- 水压升级提升清洁速度，水箱升级增加容量；修复不会消耗金币。
- V 进入第一人称漫步，点击场景锁定鼠标，WASD 移动、Shift 加速、Esc 释放鼠标。
- 点击收集 5 枚星星纪念章；P 进入拍照取景并保存 PNG。
- 手机支持长按清洗、拖动旋转、双指缩放，漫步模式提供前进和冲洗按钮。
- 所有设施恢复后触发完成画面，仍可继续自由探索。

## 文件

- `dist/index.html`：游戏 HUD 与弹窗容器。
- `dist/style.css`：响应式界面与视图样式。
- `dist/game.js`：三维建模、清洁碰撞检测、移动、修复、升级、存档、粒子、音效。
- `dist/vendor/`：Three.js 0.180.0 及 OrbitControls，遵循 MIT 许可。

本地存档键为 `park-revival-v1`。暂停菜单包含有确认步骤的重新开始功能。

## 边界

这是完整可玩的小型浏览器游戏原型。存档不跨设备同步；第一人称采用简化碰撞体。字体下载失败时自动回退到系统字体。浏览器不支持 WebMCP 时不影响任何正常游戏功能。

## 验证记录

通过真实 Chrome 浏览器验证了画布射线清洗与耗水、补水、快捷键切换、设施导航、维修条件、升级扣费、刷新后存档恢复、帮助与拍照、全部五座设施维修及通关奖励、第一人称切换、390px 手机布局。修复后的重新开始与双指触控边界也已验证。没有浏览器运行时错误。

通关检查使用预清洁存档准备维修阶段，实际清洗另用真实鼠标按住画布验证；并未手动将每个部件逐一清洗。当前 Chrome 不支持原生 WebMCP，因此该可选接口无法在支持的上下文中验证。
