# WILD HOOPS · 高个子俱乐部

可直接在浏览器中玩的 Three.js 3D 动物街头篮球游戏。长颈鹿高高、斑马条条和兔子跳跳组成荒野全明星，对抗电脑球队。

## 本地运行

需要 Python 3，直接运行：

```sh
python3 -m http.server 4289 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4289 。无需安装依赖或构建。Three.js 0.180.0 已包含在 `dist/vendor` 中，许可证随附。网页字体请求失败时会回退到系统字体。

## 玩法

- 半场 3 对 3，先得 15 分或 3 分钟结束时领先者获胜；平局进入下一次得分决胜的加时。
- 蓄力投篮、三分、近篮扣篮、传球自动切换球员、抢断、盖帽、篮板、体力冲刺。
- 防守篮板或抢断后必须出三分线；24 秒进攻计时，碰框后的进攻篮板重置 14 秒。
- 三名球员拥有独立属性与 6 秒强化技能，技能冷却 24 秒。
- 快速对战、无对手自由训练、三站递增难度联赛，不同球场配色。
- 胜负结算、街头币、六级球员成长、本浏览器 localStorage 存档。
- 触屏摇杆、动作按键、两种比赛视角、可切换合成音效、全屏、暂停。

## 操作

| 动作 | 键盘 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 蓄力投篮 / 防守盖帽 | 按住空格，在绿色区域松开 |
| 传球 / 防守换人 | E |
| 抢断 | F |
| 冲刺 | Shift |
| 球员技能 | Q |
| 切换镜头 | C |
| 暂停 | Esc / P |

手机使用屏幕内摇杆和按键。传球后自动切换到接球者。

## 文件

- `dist/index.html`：游戏 UI、HUD、入口与元信息。
- `dist/style.css`：桌面、手机与横屏布局。
- `dist/game.js`：场景、动物模型、比赛状态机、AI、音效和进度。
- `.openai/hosting.json`：静态站点发布配置。

本版是单人对抗 AI 的街机篮球游戏，进度保存在当前浏览器；不包含网络多人对战或跨设备云存档。
