# Wyldkeep · 云野生灵

一个使用 Three.js 和 Vite 实现的中文 3D 生物养成游戏。

## 启动

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5188
```

打开 http://127.0.0.1:5188 。生产构建使用 `npm run build`，输出在 `dist/`；`npm run preview` 可预览构建。

## 玩法

- **互动浮岛**：鼠标拖动旋转、滚轮缩放，点击小龙抚摸，点击紫色水晶采集资源。水晶 30 秒后重新生长。
- **照顾与成长**：三种食物、陪伴玩耍、12 秒小憩；饱食、幸福、精力影响行动。每 100 经验升一级，小龙模型随等级变大。
- **探索**：萤光草甸、迷雾森林、星落山谷分别消耗不同精力，等待 10–20 秒后获得货币、食物、经验。山谷需 3 级解锁。
- **孵化**：三种属性龙蛋，等待 45–75 秒后亲手破壳。图鉴中可以切换伙伴；当前版本共享成长数值。
- **资源循环**：星叶币购买食物、龙蛋；月光石兑换莓果；首次完成喂食和玩耍奖励 50 星叶币。
- **氛围功能**：昼夜切换、程序合成的轻音乐、伙伴命名、移动端布局。
- **存档**：浏览器 localStorage 自动保存。孵化使用真实时间，刷新后可继续；探索和休息应保持页面打开至完成。

所有 3D 资产均为代码构建的几何模型，无需外部模型资源。界面字体可选加载 Google Fonts，失败时使用系统字体。

## 结构

- `src/world.js`：3D 场景、程序化小龙、环境、拾取、动画与镜头。
- `src/main.js`：游戏状态、养成与经济、孵化、探索、图鉴、存档和 UI。
- `src/style.css`：响应式界面。
- `output/playwright/`：运行检查截图。
