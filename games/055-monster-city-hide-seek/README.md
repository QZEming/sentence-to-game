# 怪怪街区 · LITTLE IMPOSTORS

一款基于 Three.js 的 3D 非对称躲藏小游戏。玩家选择躲藏者或搜捕者，另一方由 AI 控制；不是联网多人游戏。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci
npm run dev
```

打开终端给出的本地地址。生产构建：

```bash
npm run build
npm run preview
```

`dist/` 是完整的静态发布产物，需使用 HTTP 服务打开，不能直接双击 `index.html`。字体引用 Google Fonts，无法联网时会自动使用系统字体；场景与模型均由本地代码生成。

## 玩法

- 躲藏者面对 2 名 AI 搜捕机器人。6 秒准备期后，生存 120 秒获胜；也可以收集 8 颗星糖，前往地图北侧 EXIT 传送门提前逃离。
- 搜捕者需要在 120 秒内抓住 4 只伪装的 AI 小怪兽。
- 路锥、垃圾桶、邮筒、盆栽均可伪装。静止伪装不会被发现，移动时可能暴露。
- 技能有冷却，冲刺消耗体力，停下可恢复。搜捕者抓空会损失体力。
- 提供小地图、三档 AI 难度、可选合成音效、暂停、再来一局和本地最高分。

| 操作 | 躲藏者 | 搜捕者 |
| --- | --- | --- |
| WASD / 方向键 | 移动 | 移动 |
| Shift | 冲刺 | 冲刺 |
| Q | 靠近物品伪装 / 解除伪装 | 感知最近怪兽距离 |
| E | 烟雾掩护 4 秒，冷却 15 秒 | 扫描 10 米范围，冷却 12 秒 |
| 空格 | 诱饵，冷却 18 秒 | 2.8 米内抓捕 |
| Esc | 暂停 / 恢复 | 暂停 / 恢复 |
| 鼠标拖动 / 滚轮 | 旋转 / 缩放视角 | 旋转 / 缩放视角 |

窄屏提供方向按钮，技能卡可以直接点击。
