# STRATA · 深层勘探

浏览器 3D 地质扫雷推理游戏。无需构建，所有游戏代码与 Three.js 在 dist 中，直接静态托管即可。

## 本地运行

```sh
npm start
```

打开 http://localhost:4173 。测试使用 `npm test`，不需要安装依赖。

## 操作

- 拖拽旋转，滚轮缩放；左侧切换作业层，右上角展开地层、复位或俯视。
- 1–4：钻探、标记、声呐、安全取芯。右键快捷标记。
- WASD / 方向键选格；矿区画布获得焦点后 Enter 作业；Q / E 切层。
- 普通钻探消耗 2 能量，矿物探明后再次点击采集。空洞造成 30 完整度损失。
- 安全取芯消耗 8 能量，安全揭示任意格并直接采集矿物。每份矿物返还 5 能量。
- 数字是原始矿藏 / 空洞的 26 邻域计数（包含上下层，排除自身）。采集和加固不会改变读数。
- 声呐消耗 12 能量，报告当前层 3×3 区域总矿藏和空洞数（含中心）。
- 首次作业邻域安全；能量每 3 秒恢复 1 点；弹窗与后台页面暂停计时。
- 三种难度、每日固定种子与起点、自动保存、完成档案、可选音效。

## 实现与验证

- Vanilla ES Modules + locally bundled Three.js (MIT license in dist/vendor)。
- 支持 WebGL，无法初始化时降级为保留完整规则的可操作平面网格。
- Node 原生测试验证邻域、生成、资源、伤害、取芯、标记、声呐、终局、存档与安全提示。
- 本地浏览器冒烟覆盖渲染、首击、切层、展开、标记、帮助弹窗、续玩、每日模式和移动端。
- 进度与记录仅保存在当前浏览器；清理站点数据会清空进度。
- 字体使用 Google Fonts，离线自动回退本机字体，游戏资源本身无 CDN 依赖。
