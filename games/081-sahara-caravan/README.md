# 沙海行商 · Sands & Silk

可直接游玩的单人 3D 沙漠商队经营游戏。使用 Three.js 和原生 JavaScript，所有游戏逻辑在浏览器运行，无需账号或后端。

## 游玩

- 在六座城镇的产地市场低价购入货物，前往有需求的城市售出。
- 点击地图城镇，再加入最多五站的行程。每段抵达后可交易、补给和接续旅程。
- 饮水与口粮在启程时消耗；低士气和沙尘天气延长行程。休整恢复士气。
- 升级骆驼、护卫、水囊与向导；完成四项限时委托和五个成就。
- 途中可遇到旅人、遗迹、沙暴和流动商人；选择时自动暂停。
- 可拖拽旋转、滚轮缩放、切换昼夜和环境声音。空格暂停，M 商队，C 委托，J 日志。
- 自动保存到当前浏览器的 localStorage；不在设备间同步。清除浏览器数据会丢失存档。

建议第一程：曙光绿洲买入椰枣，前往白盐古城卖出，或接受「北方的甜蜜」后交付12箱椰枣。

## 本地运行

在当前目录执行 `npm start`，打开 http://localhost:4173 。端口被占用时，可执行 `python3 -m http.server 4186 --directory dist`。

无需安装依赖或构建。Three.js 已随项目分发，许可证位于 `dist/vendor/THREE-LICENSE.txt`。中文网页字体通过 Google Fonts 可选加载；断网时回退到系统字体。

## 检查

`npm run check` 检查语法；`npm test` 运行游戏规则验证，覆盖经济套利、交易旅行循环、资源边界、暂停、任务交付/逾期、升级、事件救济、成就幂等和存档恢复。

目录：`dist/engine.js` 游戏规则；`dist/scene.js` 3D 世界；`dist/app.js` 界面与存档；`dist/style.css` 响应式样式。

生产发布使用 `.openai/hosting.json` 配置的静态目录 `dist`。
