# 森灵问答 · Wild Wisdom

一款可直接在浏览器游玩的中文 3D 奇幻知识竞技游戏。单人对 3 位 AI，所有进度仅保存在当前设备浏览器。

## 单文件离线版

交付文件 wild-wisdom-offline.html 内含代码、题库、渲染库和图片，可保存后用现代桌面浏览器打开。无需安装或额外下载。重新生成：`python3 scripts/build-standalone.py`。

## 本地运行

在项目目录运行：

```sh
python3 -m http.server 14173 --bind 127.0.0.1 --directory dist
```

然后打开 http://127.0.0.1:14173/ 。必须通过 HTTP 运行，以加载 ES modules 和 JSON 题库。

## 玩法

- 4 位可选动物：阿栗（自然题加分）、绵绵（额外时间）、竹竹（一次失误保护连击）、星咕（额外提示）。
- 经典赛：8 题、20 秒；疾速赛：12 题、12 秒；自由练习：10 题、不限时。
- 48 道稳定常识题，涵盖自然秘境、星空奥秘、奇妙科学、文明传说。每局抽取不重复题目。
- 连击、速度奖励、排除错项、增加时间、双倍积分，以及第 3、6 回合的特殊事件。
- 奖励金币、水晶、经验与 6 项成就；商店可解锁 3D 王冠和两种场景色彩装扮。
- 赛后知识手记，展示每题正确答案及解释。
- 1–4 作答，Q/W/E 使用技能，Space 进入下一题，Esc 暂停。拖动场景旋转视角。
- 页面切换至后台自动暂停。支持触摸操作、键盘操作和减少动态效果偏好。

## 实现

原生 JavaScript / CSS 与本地 vendored Three.js r170，无构建步骤，无运行时 CDN 依赖。3D 场景为实时网格，森林背景由 ImageGen 原创生成。Three.js 许可证位于 dist/vendor/THREE-LICENSE.txt。

支持 document.modelContext 的浏览器可注册读取状态、开赛、提交答案三个 WebMCP 操作；不支持该实验 API 的浏览器正常通过界面游玩。
