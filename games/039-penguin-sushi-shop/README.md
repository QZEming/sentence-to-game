# 冰山寿司 · Penguin Sushi

一个使用 Three.js 和 Vite 构建的中文 3D 烹饪时间管理游戏。

## 启动

```sh
npm install --registry=https://registry.npmjs.org
npm run dev -- --host 127.0.0.1 --port 5188
```

打开 http://127.0.0.1:5188 。生产构建：`npm run build`。

## 玩法

选订单 → 米饭 → 对应配料 → 制作 → 出餐。首个操作后开始每日 180 秒倒计时。

- 3 种寿司、动态订单、顾客耐心与超时离开
- 连击小费、满意度、每日 8 单奖励、日终结算与难度递增
- 3 种厨房升级，每种 3 级；金币、天数和升级本地自动保存
- 企鹅工位移动与制作动画、飘雪、可旋转缩放的 3D 浮冰餐厅
- 音效开关、暂停、后台自动暂停、食谱和操作指南
- 键盘：1 米饭、2 三文鱼、3 甜虾、4 黄瓜、空格制作、Enter 出餐、R 清空、P 暂停
- 适配桌面和手机；3D 场景需要 WebGL
