# 荷间 · LILYBOUND

一个 Three.js 构建的 3D 荷塘跳跃游戏，无需后端。全部模型、荷叶、莲花、青蛙、粒子及音效均在本地程序生成，不依赖图片、模型或字体 CDN。

## 启动

```bash
npm install --registry=https://registry.npmjs.org
npm run dev -- --port 5278
```

打开 http://localhost:5278 。生产构建：`npm run build`；预览产物：`npm run preview`。

## 操作

- 按住空格蓄力，松开跳跃。浅色区域是推荐力度，虚线提示落点。
- 点击相邻荷叶瞄准；← → 或 A / D 切换目标，可跨过一片荷叶。
- 拖动场景轻微环顾，R 重开，Esc 暂停。
- 触屏使用底部「按住起跳」按钮。

## 玩法

三章共 27 片路线荷叶，各章拥有 8 颗可收集露珠。章节依次增加漂流叶移动幅度与蜻蜓碰撞挑战；侧栏也可直接选择章节。

- 普通荷叶：安全落脚点。
- 漂流荷叶：随波移动，起跳后还会继续漂移。
- 枯叶：停留 4 秒后下沉，尽快再次跳跃。
- 莲花驿站：保存本章重生点，恢复三颗勇气。
- 落水或撞到低飞蜻蜓：失去一颗勇气，在存档点重生。
- 最后一片莲台：结算露珠、用时与跳跃次数，前往下一章。

包含暂停、音效开关、说明弹窗、触屏布局、程序生成水面与萤火虫、自动跟随镜头。通关最快时间存储于本地 localStorage。

## 结构

- `src/main.js`：场景、模型、输入、碰撞、关卡状态与界面同步。
- `src/style.css`：桌面及移动端界面。
- `index.html`：游戏 HUD 与弹窗。
- `output/playwright/`：实测截图。

需要支持 WebGL 的现代浏览器。首次安装依赖需要网络；构建后游戏本身无外部资源请求。
