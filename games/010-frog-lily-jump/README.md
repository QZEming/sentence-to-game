# 荷塘奇跃 · Lilybound

一个中文、可独立静态部署的 Three.js 3D 青蛙跳跃游戏。

## 运行

在本目录运行 `python3 -m http.server 4197 --bind 127.0.0.1 --directory dist`，打开 `http://127.0.0.1:4197`。渲染库已随项目提供；字体可使用系统字体回退。浏览器需要支持 WebGL 2。

## 操作

- 点击前方荷叶，或按左右方向键 / A、D 选择落点。
- 按住空格或屏幕跳跃按钮蓄力，在蓄力条浅色区域松开。
- Esc 暂停，R 返回最近存档点，M 开关声音。
- 手机上点击荷叶选择目标，按住右下角按钮后松开跳跃。

## 游戏内容

- 30 段主路线，晨光浅塘、流萤水道、月影深潭三个环境。
- 6 处金色奖励支线、移动荷叶、3 秒下沉荷叶、弹跳花与一次性护盾。
- 中心落点连击、露光收集、计时、星级与个人最高分。
- 每 5 片荷叶自动保存检查点；落水无限重试，可续玩本地进度。
- 动态水面、荷叶浮动、蜻蜓、荷花、跳跃轨迹、粒子与合成音效。

## 文件

- `dist/index.html`、`dist/style.css`：游戏界面与响应式布局。
- `dist/game.js`：3D 场景、交互和游戏状态机。
- `dist/mechanics.js`：关卡、跳距、安全落点计算。
- `dist/vendor/`：Three.js 0.180.0 及 MIT 许可证。

`output/playwright/` 保留本地验收截图，不参与发布。存档与纪录保存在当前浏览器的 localStorage，不跨设备同步。
