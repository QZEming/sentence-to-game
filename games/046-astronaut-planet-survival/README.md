# OUTPOST · 异星余生

基于 Three.js 的单机 3D 生存制作游戏。无需账号与后端，支持浏览器本地自动存档。所有游戏模型均由程序生成。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install --registry=https://registry.npmjs.org
npm run dev
```

打开 http://localhost:5187 。生产构建运行 `npm run build`，产物位于 `dist/`，可部署到任意静态站点服务。`npm run preview` 可预览构建。

## 操作

- WASD / 方向键移动，Shift 奔跑；拖拽旋转视角、滚轮缩放。
- E 采集附近资源；在着陆舱附近补充氧气。长按可连续采集。
- B 打开建造蓝图，选择建筑后点击地面放置；R 旋转，Esc 取消。
- C 打开制造终端；I 打开背包，点击使用食物、水或氧气罐。
- F 扫描并标记附近资源 15 秒。
- Esc 暂停；右上角 ? 查看生存手册。

针对桌面键盘与鼠标设计。窄屏有自适应布局，但尚未实现触控移动摇杆。

## 生存循环

采集铁矿、晶体、纤维、冰矿 → 制造补给和合金 → 建造避难舱与太阳能阵列 → 建立深空通讯信标。

六种建筑：紧急避难舱、太阳能阵列、冰矿提取器、生态种植舱、通讯信标、照明灯。制造系统包含合金、饮用水、口粮、氧气罐与采集工具升级。采集器升级使单次产量从 3 提高到 5。

每个资源点可采集四次，耗尽后 120 秒再生。生命、氧气、饱食和水分分别管理，奔跑增加消耗。靠近避难舱可以恢复生命与氧气，太阳能阵列提升补氧效率。提取器和种植舱每 30 秒自动产出补给。

一个昼夜为 10 分钟。每 5 分钟有一次 60 秒离子风暴；风暴增加户外氧气消耗并造成伤害。生命耗尽后可以在着陆点应急复苏，保留资源和建筑。发送信号后仍可继续自由探索和建造。

存档每 15 秒以及制造、建造和关闭页面时保存至浏览器 localStorage，键名为 `outpost-echo-v1`。清除该站点浏览器数据即可重新开始。存档不跨设备同步。
