# 夜航电台 · Nightfall Radio

中文 3D 互动叙事浏览器游戏。1997 年的暴雨夜，你在雾港主持 FM 89.7，通过六通来电和广播，决定一位少女、一段旧事故真相和下街居民的命运。

## 本地运行

```bash
npm start
```

打开 http://localhost:4173 。需要 Python 3；游戏运行不依赖构建或后端。Three.js 已随静态文件附带。中文字体在线不可用时会使用系统字体。

## 玩法

- 点击接听或按 E，六通来电各有三种回应。
- 每通来电期间可广播一期节目：音乐安抚、公开证据、疏散通知。
- 用 1–4 打开直播间、频率扫描、小镇地图、节目日志。
- 拖动 3D 场景改变视角；桌上的电话、收音机、话筒、唱片机、笔记本、台灯与备用配电箱可以点击。
- 扫描 87–97 MHz，手动调频或自动搜索隐藏线索。
- 根据便签顺序恢复备用电路，每夜获得一次额外电力。
- 信任、信号和电力决定救援与广播的效果。没有实时倒计时，阅读和思考不会损失资源。
- 救援与真相公开组合成四个结局，疏散另有独立尾声。
- 支持浏览器本地自动存档、重开、键盘、移动屏幕、减少动态效果偏好。

声音通过 Web Audio 合成，不需要外部音频文件；来电朗读使用设备中文语音，具体音色和可用性取决于浏览器。

## 验证

```bash
npm run check
npm test
```

测试覆盖四个结局、2,187 条完整路径、关键救援门槛、重复操作保护、损坏存档恢复。已在真实浏览器走通完整救援/公开真相/疏散流程，并验证刷新恢复、调频、配电修复和 390×844 移动布局。

## 文件

- `dist/index.html` / `style.css`：游戏界面和响应式布局
- `dist/scene.js`：Three.js 直播室、鼠标交互、雨景、光照与黎明
- `dist/game.js`：独立叙事状态机、选择效果、结局与存档读取
- `dist/app.js`：界面与状态连接
- `dist/audio.js`：雨声、电话铃、合成音乐和来电朗读
- `tests/game.test.mjs`：可直接在 Node.js 执行的逻辑测试
