# 风屿 · 天气精灵

一个中文单人 3D 生态调控游戏。浏览器需要支持 WebGL。

## 运行

无需安装依赖或编译。Three.js 0.169.0 已本地打包，保留 MIT 许可证。

```sh
python3 -m http.server 4189 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4189 。不要使用 file:// 打开，浏览器 ES 模块需要 HTTP。

## 玩法

- 61 个独立模拟地块，各有水分、养分、植被成长和健康。
- 唤雨、暖阳、微风、播种、落雪、复苏六种能力；能量自然恢复。
- 绒绒草、星铃花、云杉、溪岸柳四种植物，各自适水范围不同，可以改种。
- 春夏秋冬影响成长和蒸发，秋风传播更远，雪被缓慢释放水分。
- 雨后初晴、春芽苏醒、风播雨润三种天气连携。
- 蝴蝶、兔、鸟、蜂、鹿五种动物，按环境条件返回；授粉、种子传播和能量回馈。
- 六段渐进任务、随机式周期天气事件、生态图鉴、岛屿手记、胜利后自由守护。
- 支持鼠标拖动、缩放、触屏操作、数字键 1–6、空格暂停、1/2/3 倍速、音效开关。
- 每 5 秒保存到本机 localStorage；关闭或隐藏页面时模拟停止，不跨设备同步。

## 验证

```sh
node tests/ecology.mjs
node --check dist/engine.js
node --check dist/scene.js
node --check dist/app.js
```

已验证生态状态变化、改种与重复播种、连携、暂停、季节冷却、灾害化解、存档恢复、5 种动物和完整胜利条件。通过 Chrome 实际点击验证降雨任务推进、播种成长、季节切换、图鉴；检查了桌面及 390×844 手机布局，主要游戏流程未出现阻断性错误。

可选 WebMCP 工具在支持 document.modelContext 的浏览器中注册。当前检查未执行 WebMCP 工具调用，因此该可选接口未经端到端验证；常规界面与游戏流程已验证。

## 文件

- `dist/engine.js`：与渲染分离的生态模拟与任务逻辑。
- `dist/scene.js`：Three.js 场景、地块拾取、天气粒子、精灵与动物。
- `dist/app.js`：界面交互、音效、图鉴、存档与浏览器入口。
- `dist/style.css`：桌面、手机、自适应布局。
- `dist/vendor/`：本地渲染依赖与许可证。
