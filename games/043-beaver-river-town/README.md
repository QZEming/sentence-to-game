# 柳溪镇 · Willowbrook

一个使用 Three.js 构建的中文 3D 海狸城市建设游戏。所有模型由程序生成，无需外部图片或模型服务。

## 运行

```bash
npm install
npm run dev -- --port 5188
```

打开 http://localhost:5188。生产构建：`npm run build`；预览构建：`npm run preview`。

## 玩法

- 9 种建设工具：道路、运河、水坝、小屋、伐木工坊、农田、取水站、松林、花园。
- 水道连通计算与周围土地灌溉。农田、取水站需要邻近水源；生产建筑需要道路。
- 木材、食物、饮水、人口、住房容量和幸福感模拟。资源不足会导致居民离开。
- 每 8 天交替春季与旱季。旱季饮水减产，水坝可恢复取水产量。
- 建筑可升至 3 级；拆除返还一半木材，清理天然树木获得木材。
- 发展任务、任务奖励、自动保存、手动保存、重新开始。
- 1× / 2× / 3× 速度和暂停。一个游戏日约 40 秒。

## 操作

点击底部建筑，再点击空地放置。点击已有建筑可查看状态并升级。

- `1–9`：选择建筑
- `Esc`：取消选择 / 关闭窗口
- `空格`：暂停或继续
- `Q` / `E`：旋转视角
- 鼠标滚轮：缩放
- 右键拖动：平移；未选择建筑时也可左键拖动

存档存于当前浏览器的 localStorage；清除网站数据会删除存档。
