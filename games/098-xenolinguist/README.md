# 星语 · 异星田野手记

一款中文 3D 外星语言破译游戏。扮演初次接触外星文明的语言学家，从居民动作、物品与场景推断文字含义，再用语言改变世界。

## 本地运行

这是完全静态的浏览器游戏，Three.js 已随项目提供，无需安装依赖或运行构建。

```bash
cd xenolinguist
python3 -m http.server 4317 --bind 127.0.0.1 --directory dist
```

打开 `http://127.0.0.1:4317`。ES modules 需要 HTTP 服务器，不能直接双击 HTML 文件运行。

## 游戏内容

- 4 个 3D 区域：潮汐聚落、种子交换庭、沉睡灯圃、月影门廊。
- 12 个外星词语，每词 2 种行为语境，共 24 条证据。
- 观察、证据记录、候选词义假设、成组语境验证、SOV 句子组合、章节解锁。
- 错误词义与错误语序反馈；可重复观察与提示；不惩罚试错。
- 四步迎客仪式与完整结局。
- 4 件文明遗物、6 项成就、指代练习、活灯调光支线、随行活灯。
- 浏览器本地自动保存、档案 JSON 导出、重新开始。
- 桌面键鼠与手机触控、镜头旋转缩放、合成环境音与音节。

## 操作

- WASD / 方向键：移动。
- 点击地面：前往位置。
- 拖动场景：环视；滚轮：缩放。
- 点击观察点，或在附近按 E：观察。
- J：桌面切换词典/手记，手机打开词典。
- Esc：关闭当前面板。
- 手机方向按钮移动，点击居民标记互动。

## 文件

- `dist/index.html`：游戏主界面。
- `dist/main.js`：游戏状态、证据、词典、谜题、存档、声音与 UI。
- `dist/world.js`：Three.js 场景、角色、行为动画、移动、镜头与环境。
- `dist/data.js`：词汇、证据、语法、章节、奖励及成就数据。
- `dist/style.css`：桌面、手机和低高度视口的布局。
- `dist/vendor/`：Three.js 本地运行时与 MIT 许可证。

存档保存在当前浏览器 localStorage 的 `lingua-expedition-v1` 中，不会发送到服务器。导出的 JSON 是可读田野档案，当前不提供导入功能。音效仅在用户交互后启用。游戏需要 WebGL 支持。
