# 午夜恶作剧 · Midnight Mischief

一个中文 3D 古堡家具机关连锁解谜游戏。使用 Three.js 与 Vite，所有场景模型均由代码生成，无需下载图片或 3D 资源。

## 运行

```bash
npm install --registry=https://registry.npmjs.org
npm run dev
```

生产构建：`npm run build`，将 `dist/` 部署到任意静态网站服务。支持子目录部署。需要启用 WebGL 的现代浏览器。

## 玩法

- 点击场景中的家具或下方卡片附身，点击「发动恶作剧」或按 E 使用能力。
- 数字 1–5 快速选择家具；WASD / 方向键移动幽灵；空格消耗 8 灵力冲刺。
- 鼠标拖动旋转视角，滚轮缩放；左下角按钮可旋转和重置视角。
- 按左侧线索完成三个机关步骤，使住客惊吓值达到 100%，解锁下一房间。
- 灵力每秒恢复 4 点，恶作剧有 2 秒冷却。
- 每间房探索全部五件家具可解锁隐藏记忆，在「幽灵手册」查看。解锁和记忆保存在 localStorage。
- 无提示、最多四次恶作剧完成关卡获三星；另有二星及一星评价。
- 右上角可开启程序合成音效、查看帮助。支持移动端点按游玩。

## 房间

1. 月光会客厅：座钟 → 唱片机 → 吊灯。
2. 低语图书室：壁炉 → 魔法书架 → 骑士盔甲。
3. 午夜宴会厅：座钟 → 魔法餐桌 → 吊灯。

## 验证

`npm run build` 通过。Playwright 在桌面 Chrome 中完成三关通关、解锁验证；390px 手机布局无横向溢出，浏览器无 JavaScript 异常。

截图及浏览器检查脚本在 `output/playwright/`。检查脚本使用本地 5174 端口与 macOS Chrome 路径，可按环境调整。
