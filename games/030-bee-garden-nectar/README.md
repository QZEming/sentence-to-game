# 蜜境 · Honey Garden

一个以 Three.js 构建的浏览器 3D 采蜜游戏。静态部署，无后端、无账号要求，使用浏览器 localStorage 自动存档。

## 本地运行

```sh
python3 -m http.server 8080 --directory dist
```

打开 http://localhost:8080。不要直接以 file:// 打开，因为游戏使用 JavaScript 模块。

## 操作

- WASD / 方向键：按屏幕方向飞行
- 点击地面、花朵或小地图：自动导航
- 停在花朵旁：自动采蜜；采空后完成授粉，花朵随后再生
- Shift：加速；Space：提高飞行高度
- H：回蜂巢，自动把花蜜换为蜂蜜并恢复体力
- B：花朵图鉴；U：蜂巢升级；R：60 秒花间竞速
- Q / E 或右键拖动：旋转；滚轮、＋、−：缩放
- Esc：暂停；摄影模式下返回游戏
- 手机：左侧摇杆移动，ϟ 加速，点地面导航

## 内容

四种各有花蜜价值的花、连续授粉奖励、三条进阶任务、三种三级升级、昼夜循环、萤火虫、雨天加成、黄蜂巡逻、无掉落的安全回巢、竞速计时与个人纪录、合成轻音乐、图鉴、摄影模式、自动存档及明确确认后的重置。

核心结算校验：`node check.mjs`。WebGL 2 和硬件加速是运行条件。进度只保存在当前浏览器，清理网站数据会删除存档。
