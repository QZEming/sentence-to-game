# NULLSHIFT · 失重边界

中文第三人称 3D 太空逃生游戏，使用本地随附的 Three.js r170。无需安装依赖或构建。

## 本地启动

```sh
python3 -m http.server 4317 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4317 。需要支持 WebGL 的浏览器；字体下载失败时会回退到系统字体。

## 操作

- WASD / 方向键：沿飞船移动，D / 右箭头向前。
- Q：翻转上下重力，消耗 25 电容，落地后加快充能。
- Space：跳跃，空中再次按下可消耗电容推进。
- Shift：冲刺，额外消耗氧气。
- E：回收核心、读取日志、操作控制器与逃生舱。
- Esc：暂停 / 继续。手机提供方向键、跳跃、交互、翻转按钮。

## 关卡

1. 破损生活舱：沿天花板穿越地板裂口，在上方回收第一枚核心。
2. 激光维修廊：避开下方和上方激光，在地板回收第二枚核心。
3. 失稳反应堆：跨过电弧与低重力区域，在天花板解除护罩，回到地板回收最后核心。
4. 靠近右端逃生舱并按 E 完成撤离。

包括氧气补给、宇航服修复、三个可选船员日志、舱段检查点、失败重试、合成音效、通关评级和设备本地最佳纪录。切换标签页与暂停都会停止游戏计时。已收集核心、日志、解除的护罩在检查点重试时保留。

## 文件

- `dist/index.html`：中文界面及操作区域。
- `dist/style.css`：响应式 HUD、菜单与触屏布局。
- `dist/world.js`：3D 飞船、宇航员、灯光、关卡对象。
- `dist/game.js`：固定步长物理、重力、交互、音效与胜负状态。
- `dist/vendor/three.module.js`：Three.js，引擎许可证见同目录 `LICENSE.txt`。

## 验证记录

已在 Chromium 中用真实键盘输入完成：第一核心 → 第一隔离门 → 交替激光 → 第二核心 → 坠落失败 → 检查点重试 → 反应堆控制器 → 第三核心 → 逃生成功。通关过程中无控制台错误或警告。另检查了 1440×900 桌面和 390×844 手机布局，手机无横向溢出。

可选 WebMCP 接口在当前浏览器中不可用，因此其运行时验证未进行；不影响普通游戏操作。
