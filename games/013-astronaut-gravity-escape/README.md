# 失重协议 · Gravity Protocol

Three.js 3D 重力逃生游戏。玩家在破损的 ARK–07 中改变四向重力，回收三枚能源核心并启动逃生舱。

## 启动

```bash
npm install --registry=https://registry.npmjs.org
npm run dev
```

打开终端显示的本地网址。`npm run build` 生成 `dist/`；`npm run preview` 预览生产构建。

## 操作

- W / S：沿船舱前后移动；A / D：沿当前重力平面横移。
- Q / E：逆时针 / 顺时针切换重力。右侧罗盘也支持点击。
- 空格：使用反重力推进器，松开后自动充能。
- Shift：加速移动。
- F：拾取附近核心和补给，或启动逃生舱。
- R：扫描最近的核心。
- Esc：暂停 / 继续。鼠标拖动旋转视角，滚轮缩放。

## 目标与机制

核心分别位于甲板、右侧舱壁和天花板。三枚全部收集后，切换回甲板重力，前往远端发光舱门并按 F 逃生。氧气会逐渐消耗；白色补给罐恢复氧气和宇航服完整度，核心也提供少量氧气。电弧周期性启停，天花板可以绕开。右侧船体破口会造成伤害。推进器有独立能量并额外消耗氧气。失败或成功后都可重新开始。

模型、舱室、星空及音效均由代码生成，无需外部美术素材。适合有键盘鼠标和 WebGL 支持的桌面浏览器。字体使用系统字体，无需外部字体服务。
