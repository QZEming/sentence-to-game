# Snowball Social · 雪球保龄球

一个使用 Three.js 和 Vite 构建的 3D 雪地保龄球游戏。所有场景模型由代码生成，无需下载模型或贴图。

## 运行

```sh
npm install
npm run dev
```

生产构建：`npm run build`，预览构建：`npm run preview`。

## 玩法

- 方向键、滑杆或在场景中左右拖动：瞄准。
- 按住空格键或发球按钮蓄力，松开发球，推荐 65–85% 力量。
- A / S / D：左旋 / 直球 / 右旋。
- P：暂停。右上角按钮可切换音效、俯瞰视角和全屏。
- 经典：完整十局标准保龄球计分，含全中、补中和第十局奖励球。
- 暴风雪：每球随机侧风。
- 极限挑战：利用旋转绕开会反弹雪球的冰晶。
- 切换模式或点击“再来一场”会开启新比赛，个人最佳在本地保存。

## 实现

`src/main.js` 包含程序化雪山、松林、木屋、雪人、雪球、粒子效果、音效和碰撞模拟。`src/scoring.js` 独立实现标准计分。碰撞是针对游戏玩法的轻量近似模拟，不是完整三维刚体引擎。

界面支持桌面和移动端，需要支持 WebGL 的现代浏览器。界面使用系统字体，游戏不依赖远程服务。
