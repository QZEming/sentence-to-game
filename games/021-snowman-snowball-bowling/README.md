# SNOWBOWL · 雪人保龄球俱乐部

静态网页 3D 游戏，Three.js 渲染 + cannon-es 刚体物理。

## 本地运行

`python3 -m http.server 4267 --directory dist`

打开 `http://localhost:4267`。无需构建或安装依赖，运行库已保存在 `dist/vendor/`。

## 玩法

- 经典赛：10 轮标准保龄球计分，支持全倒、补中和第十轮奖励球；比分显示已结算轮次。
- 冰雪挑战：5 关，每关最多两球；冰块、移动冰阵、左右侧风、金色奖励光环。
- 自由练习：不限轮次，可试用经典、巨型和爆裂雪球。
- 左右键／方向滑杆瞄准，A / D 调整站位，Q / E 调整旋转，按住空格或投球按钮蓄力，松开投球。
- Enter 继续投球；P 暂停；右上角开启音效或查看说明。
- 挑战计分：每瓶 10 分，全倒额外 50 分，补中额外 20 分，穿环额外 25 分。
- 最佳成绩保存在当前浏览器的 localStorage。

## 验证

`node test-scoring.mjs` 验证满分局、连续补中、普通局、第十轮奖励球等计分边界。

支持 WebGL 的现代浏览器。背景切换自动暂停。电脑和手机均提供完整投球操作。

第三方库：Three.js 0.170.0（MIT）、cannon-es 0.20.0（MIT）。
