# IRON CIRCUIT — 铁环机甲擂台

一个无需登录的浏览器 3D 近战机甲游戏，使用本地打包的 Three.js 0.180.0。

## 本地运行

```sh
cd iron-circuit
python3 -m http.server 4174 --directory dist
```

打开 http://localhost:4174。无需 npm 安装或构建。浏览器需要支持 WebGL2。

## 内容

- 五个装配槽位、16 个部件、4 种武器、4 种涂装，装配立即更新模型与性能。
- 三名风格不同的联赛对手、轮间整备、冠军结算。
- 逐波强化的生存挑战，每三波双机夹击；无限训练场。
- 三段连击、蓄力重击、格挡/精准弹反、推进闪避、三种核心技能。
- 能量管理、架势击破、撕裂、过载、纳米修复和周期性场地高温。
- 零件研发、战绩与设备本地自动存档；移动端触控按钮。
- 战斗音效可通过右上角音符开关开启。

## 操作

WASD / 方向键移动，J 连击，K 重击，Space 闪避，Shift / L 格挡，Q 核心爆发，Esc / P 暂停。机库可拖动旋转、滚轮缩放。

## 结构

- `dist/main.js`：装配界面、赛事和本地进度
- `dist/engine.js`：3D 场景、输入、敌方 AI、伤害和反馈
- `dist/data.js`：部件属性、对手与存档校验
- `dist/mech-assets.js`：带关节的机甲与擂台几何资产
- `dist/vendor/`：Three.js 与 MIT 许可证

所有游戏逻辑及资产随文件提供。Google Fonts 为可选字体，离线时使用系统字体。存档位于当前浏览器的 localStorage，不跨设备同步。
