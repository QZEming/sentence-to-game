# 符文决斗 · Runeweaver

可直接部署的 Three.js 3D 单人魔法决斗游戏，所有运行依赖均已放入 `dist/vendor`。无需构建。

## 本地运行

```sh
npm run dev
```

打开 http://localhost:4173 。需要支持 WebGL 的现代浏览器。字体可联网加载，离线时使用系统字体。

## 玩法

- Q / W / E / R / T：火、冰、雷、土、奥术；最多组合三枚。
- Space / 点击竞技场 / 释放法术按钮：施法。
- F / 右键：使用队列最后一枚符文反制。克制环为火克冰、冰克土、土克雷、雷克奥、奥克火。
- 反制窗口：敌方咏唱最后 1.33 秒或来袭弹道阶段；最后 0.48 秒为完美反制。成功返还魔力并反射伤害；错误元素开启 0.8 秒减伤格挡。
- A / D：横移；Shift：闪避，短暂无敌。
- X：觉醒；G：符文之书；Esc：暂停；Backspace：撤销。
- 拖动手势：向上火、向下冰、横向土、Z 形雷、闭环奥术。
- 点击推荐配方或符文之书可直接装入组合。

18 种命名配方，任意一至三元素都有可用法术；六位差异化敌人、首领双阶段、无限循环试炼、九种可叠加遗物、燃烧/冻结/护盾/减速/打断、最高分本机保存、可开关程序音效。移动端支持触摸符文、手势与操作按钮。

## 文件

- `dist/scene.js`：3D 竞技场、法师模型、粒子、法术弹道。
- `dist/spells.js`：元素、法术、敌人、遗物与手势识别。
- `dist/game.js`：战斗逻辑、输入、界面与状态。
- `dist/style.css`：响应式界面。
- `dist/vendor/THREE-LICENSE.txt`：Three.js MIT 授权。

使用 `npm run check` 进行 JavaScript 语法检查。
