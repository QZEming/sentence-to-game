# RE:FACTORY · 再造工厂

一个基于 Three.js 的 3D 工厂自动化游戏。你与机器人小瓦共同建造回收流水线，把废料加工成新的材料。

## 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:5188/ 。使用 `npm run build` 生成 `dist/`，使用 `npm run preview` 检查生产构建。

## 玩法

- 8 种设备：传送带、废料入口、智能分拣机、破碎机、熔炼炉、压块机、出货仓、太阳能板。
- 废料沿设备出口箭头移动；可以转弯、合流和扩建多条产线。接错方向或下游堵塞会阻断物流。
- 金属、塑料、玻璃三种材料；分拣增值、三级加工品质、自动销售与再生库存。
- 设备可升至三级；电力不足会降低全厂效率，太阳能配套储能可昼夜供电。
- 三类循环订单，交付后下一批需求和奖励增加。
- 三条科技路线、各三级研究；四个里程碑和自由建造。
- 机器人巡逻与建造响应、设备动画、烟雾、物料动画、轻微昼夜光照变化、可选音效。
- 暂停、1/2/3 倍速；每 15 秒自动存档，刷新后恢复；存档保存在当前浏览器 localStorage。
- 桌面和手机布局；手机支持直接点击旋转建造方向。

初始工厂包含两条可工作的示范产线。建议先添加三台设备、升级一台设备，领取第一阶段里程碑奖励，再完成订单研究科技。

## 操作

| 操作 | 方式 |
| --- | --- |
| 建造 | 点击底部设备，再点击地板空格 |
| 查看设备 | 退出建造模式后点击设备 |
| 旋转 | R / 建造提示中的旋转按钮 / 设备操作面板 |
| 取消建造 | Esc / 再次点击当前设备工具 |
| 快捷选工具 | 1–9 |
| 暂停 | 空格 / 底部暂停按钮 |
| 视角 | 拖动旋转、右键拖动平移、滚轮缩放 |
| 重置镜头 | 右上角准星按钮 |
| 重新开局 | 右上角 ? → 重新开始，并确认 |

## 验证

`npm test` 运行 7 项核心模拟测试：连续生产、建造与退款、堵塞恢复、供电、订单、研究与里程碑、存档恢复。

已实际在浏览器检查建造、升级、旋转、订单交付、科技研究、暂停与 390×844 手机布局；控制台无错误。

## 实现结构

- `src/game.js`：独立模拟引擎、经济与存档。
- `src/world.js`：程序化 Three.js 场景、相机、机器人及动画。
- `src/main.js`：界面、交互与模拟循环。
- `src/style.css`：桌面和移动端布局。
- `tests/game.test.js`：Node 内置测试框架。

游戏不需要后端和外部模型资源。可选 Google Fonts 不可用时使用系统字体。需要支持 WebGL 的浏览器。
