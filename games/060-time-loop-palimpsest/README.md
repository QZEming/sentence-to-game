# PALIMPSEST · 时间回响

使用 Three.js 构建的可独立部署静态 3D 时间循环解谜游戏。所有游戏代码和 Three.js 依赖均在 `dist/` 内；在线字体不可用时使用系统字体。

## 运行

```bash
python3 -m http.server 4317 --directory dist
```

打开 `http://localhost:4317`。无需安装依赖或构建。设备需支持 WebGL 2。

## 操作

- WASD / 方向键：按当前镜头方向移动。
- 点击地面：绕开当前墙壁和关闭的门自动寻路；激光需要自己判断时机。
- R：保存本轮行动并回溯，最多 3 个回声。回声重播后停留在终点，可压住压力板。
- E：拿起或放下方块；靠近反应堆时进行稳定操作。
- Shift：奔跑。空格：消耗每轮 5 秒能量，让倒计时、回声与激光减速。
- 拖动：旋转视角。滚轮：缩放。Esc：暂停。
- 手机可点击地面寻路，或使用屏幕方向键与 E 按钮。

## 关卡

1. **第一次回响**：在 A 留下一个回声，再穿门稳定反应堆。
2. **重量与回声**：在 B 留下回声，搬方块压住 A；等激光熄灭后通过。
3. **三次约定**：依次在 A、B、C 留下 3 个回声，最后搬方块到 D；四个位置同时激活后完成干预。

每关有 3 个可选记忆碎片。超时和激光触碰会重启本轮，保留回声及本次实验已收集的碎片。回溯会重置方块。已通关记录仅保存在当前浏览器的 localStorage。

## 验证

```bash
node checks/solutions.mjs
node checks/edge-cases.mjs
node --check dist/game.js
```

解谜验证通过真实逐帧移动和交互完成三关。边界检查覆盖关门脱困、超时复原、回声上限、撤销、关卡重置与关闭门后的物品拾取阻挡。浏览器验证覆盖实际 3D 渲染、点击寻路、压力板、录制回声、暂停与帮助界面。

## 文件

- `dist/engine.js`：独立的玩法和时间系统，可在 Node 中验证。
- `dist/game.js`：Three.js 场景、输入、音效和 UI。
- `dist/style.css`：响应式界面。
- `dist/vendor/`：Three.js 0.180.0，附 MIT 许可证。

浏览器支持 WebMCP 时会注册状态读取及回溯、交互、撤销、暂停工具；其余浏览器不受影响。
