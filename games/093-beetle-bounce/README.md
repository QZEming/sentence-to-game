# Beetle Bounce · 森林弹珠

一个不依赖后端的 3D 森林弹珠街机。Three.js 负责场景，固定 120 Hz 平面物理负责弹珠和挡板。运行资源均保存在本项目，无需外部字体或 CDN。

## 运行

在此目录执行 `npm start`，打开终端显示的本地地址。需要 Node.js（语法检查）和 Python 3（静态服务），不需要安装 npm 依赖。也可以用任意静态服务器托管 `dist/`。

## 操作

- A / D 或左右方向键：左右甲虫挡板。
- 按住空格或发射按钮蓄力，松开发射；力度影响入场轨迹。
- X：震台，连续三次会倾斜并禁用挡板三秒。
- P：暂停；浏览器失焦时自动暂停。
- 手机支持左右独立触控挡板和发射按钮。

## 玩法

经典模式有三球；竞速模式发射后倒计时 90 秒，期间可无限补球。击中不同蘑菇或机关积累连击，最高 ×5。点亮三座琥珀机关后释放两颗额外弹珠，多球期间古树门奖励 2,500 基础分。每次发球享有五秒保护，每颗多球新球拥有独立四秒保护。纪录按模式保存在当前设备的 localStorage。

支持暂停、重开、声音开关、全屏、触屏、减少动画偏好、离屏自动暂停和低速球解困。支持可选 WebMCP 接口，浏览器不支持时不影响游戏。

## 验证

`npm run check` 检查语法，`node verify.mjs` 验证发射、暂停、生命、多球保护、连击与计分冷却。

Three.js v170 及其 MIT 许可证保存在 `dist/vendor/`。
