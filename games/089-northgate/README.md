# 北境哨所 · NORTHGATE

以虚构的北境联邦为背景的中文 3D 边境检查游戏。所有判定均依据证件、当日通告和货物证据。

## 运行

无需编译或安装依赖。Three.js 0.170.0 已随项目保存在 `dist/vendor/`。

```bash
python3 -m http.server 4258 --directory dist
```

打开 `http://localhost:4258`。须通过 HTTP 访问，浏览器需支持 WebGL；字体加载失败会回退到系统字体。

## 内容

- 5 天战役、30 位旅客、15 种场景组合，含到期当日有效、同名不同证件号、多违规叠加等边界。
- 真正 WebGL 3D 场景，山地、哨塔、森林、车辆、道闸、天气、扫描动画及三种镜头。
- 护照、入境许可、检疫证明、工作证、药品运输许可；可点击字段标记证据。
- X 光扫描、紫外防伪、询问、拒绝贿赂、批准/拒绝/拘留与明确纠错依据。
- 连对奖励、纪律评分、经费、设备升级、日终结算、战役评价和逐人记录。
- 当前设备自动存档、刷新后恢复已判定结果；桌面快捷键及移动端触摸操作。
- 可选浏览器 WebMCP 接口，与同一游戏状态和检查门槛一致。

快捷键：`1/2/3` 镜头，`空格` 扫描，`U` 紫外，`A` 批准，`R` 拒绝，`D` 拘留，`Enter` 下一位，`Esc` 暂停。

## 规则

拘留条件优先，普通违规拒绝，其余批准。第 2 天缺少防伪印记拒绝，第 3 天起伪造证件拘留。扫描对所有人必需；第 2 天起紫外检验必需。没有阅读倒计时。

## 验证

```bash
node --test tests/rules.test.mjs
node tests/flow-test.mjs
```

还通过浏览器验证了 WebGL 渲染、检查前提交拦截、扫描和放行奖励、判定后刷新恢复、下一位、390px 移动端无横向溢出，以及 WebMCP 的成功/失败调用。在浏览器中实际完成全部 30 位旅客、五个班次和两项升级，达到 100% 准确率 / 1005 积分；浏览器控制台未发现脚本错误。
