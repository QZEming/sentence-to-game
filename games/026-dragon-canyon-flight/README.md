# Dragonflight · 小龙飞行学院

使用 Three.js 构建的完整 3D 峡谷飞行小游戏。场景、角色、动画及音效均由代码生成，不依赖外部模型或贴图。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`；预览构建：`npm run preview`。

## 玩法

- **飞行训练**：完成 8 次穿环、收集 12 枚水晶、喷火击中 3 个靶标，获得额外 500 XP。
- **自由探索**：无限循环峡谷，没有时间限制。
- **计时挑战**：90 秒内争取最高分。
- 穿环基础分 100，连续穿环最高 5 倍；水晶 30 分、恢复 10 能量；靶标 250 分。
- 撞到峡谷边界扣 50 分与 18 能量，打断连击，并提供短暂无敌。
- 挑战和训练结算保存经验、等级及最高分到浏览器 localStorage。

| 操作 | 按键 |
| --- | --- |
| 爬升 / 俯冲 | W / S 或 ↑ / ↓ |
| 左右转向 | A / D 或 ← / → |
| 起飞 / 振翅 | 空格 |
| 冲刺 | Shift |
| 喷火 | F（42 米内、瞄准靶标） |
| 暂停 / 恢复 | Esc |

手机及平板提供屏幕操作按钮。声音默认关闭，可通过右上角音符按钮开启。离开浏览器窗口时自动暂停。

## 技术说明

Vite + Three.js，WebGL 渲染，响应式 HTML/CSS 界面。字体有系统字体回退。只读运行状态可通过 `window.dragonflight.getState()` 检查。
