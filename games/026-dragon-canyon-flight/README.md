# 御风幼龙 · SKYBOUND

以 Three.js 构建的完整浏览器 3D 飞行游戏。直接操控拥有动态双翼、尾巴和龙焰的小龙阿岚，穿越低多边形风歌峡谷。

## 开始游戏

需要支持 WebGL 的现代浏览器。代码及 Three.js 均随项目提供，无需安装依赖或构建：

```sh
cd dragon-canyon
npm start
```

打开 `http://localhost:4189`。也可使用任意静态服务器托管 `dist/`。

## 操作

- `W / S` 或上下方向键：升降；`A / D` 或左右方向键：左右移动。
- 长按 `Shift`：消耗能量进行冲刺；松开后恢复。
- `Space`：喷火击碎前方圆靶，每次消耗 8 点能量。
- `P / Esc`：暂停或继续；`Enter`：从营地起飞。
- 手机：左侧摇杆控制方向；右侧按钮支持长按冲刺和喷火。

## 玩法

- **自由翱翔**：不限时，四阶段训练引导；护盾耗尽后就近恢复，持续探索。
- **穿环竞速**：90 秒计时，每环增加 2 秒，上限 120 秒。护盾耗尽或时间结束后结算。
- **烈焰试炼**：三阶段穿环与喷火挑战，每阶段新增 4 个光环、2 个靶标目标，并恢复护盾及能量。
- 连续穿环提升积分倍率；从中心穿过额外获得 50 分。
- 晶石每枚 25 分并恢复能量；上升气流托举小龙并快速恢复能量。
- 三个区域、瀑布、石桥、岩柱、浮空岛、路线地图、粒子特效、合成音效和可切换画质。
- 本地保存经验、最高分及设置；300 XP 解锁珊瑚色，800 XP 解锁晴空蓝。存档仅属于当前浏览器。
- 支持舒缓镜头，自动根据系统减少动态效果偏好初始化。

## 文件

- `dist/index.html`：游戏界面与中文说明。
- `dist/style.css`：桌面及移动端适配。
- `dist/game.js`：场景建模、飞行、碰撞、模式、进度、输入及音效。
- `dist/vendor/three.module.min.js`：Three.js 0.169.0，MIT License。
- `.openai/hosting.json`：静态站点配置。

界面字体优先使用 Google Fonts；无法联网时自动使用系统字体。3D 引擎和游戏资源均为本地文件。游戏无需任何账户服务或后端。

## 验证

`npm run check` 检查 JavaScript 语法。已在 Chromium 中验证桌面和手机视口、穿环与收集、暂停冻结、模式切换、重开、能量消耗及恢复。核心回归检查覆盖 XP 不重复发放、快速横移穿环、结算停止计分与边界约束。
