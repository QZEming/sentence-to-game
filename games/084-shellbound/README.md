# 蜗牛骑士 · SHELLBOUND

一个可直接在浏览器中游玩的 Three.js 3D 动作肉鸽游戏。依赖已随项目提供，不需要构建或联网加载第三方脚本。

## 本地运行

```sh
cd shellbound
python3 -m http.server 4539 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4539 。不要直接用 file:// 打开，ES 模块需要 HTTP 服务。浏览器须支持 WebGL。

## 操作

- WASD / 方向键：移动；鼠标：瞄准；按住左键：攻击。
- J：自动瞄准并攻击；1–4：随时切换短剑、重锤、连弩、法杖。
- 空格：无敌翻滚；按住 Shift / K：消耗体力缩壳防御并反伤。
- Q：满能量时释放螺旋风暴，清除敌方弹幕。
- E：开宝箱 / 穿过传送门；Esc：暂停。
- 触屏：左侧摇杆移动，右侧按住攻击自动瞄准；技能和武器可点击。

## 内容

- 苔光遗迹、琥珀熔炉、月晶深窟，12 个随机布局房间。
- 5 种普通敌人，3 个攻击循环不同的首领，首领半血进入第二阶段。
- 波次战斗、橙色攻击预警、环境陷阱、可破坏木桶、宝箱。
- 4 种武器，短剑第三击剑气、重锤震荡、连弩速射、法杖爆炸。
- 15 种可叠加祝福，暴击、吸血、闪电链、寒霜、脉冲、反伤等搭配。
- 普通 / 精英 / 营火路线选择，琥珀与星屑双资源。
- 死亡结算、最终通关、可重开，星屑可用于永久生命/伤害成长。
- 本浏览器 localStorage 存档、可开关合成音效、暂停、帮助与小地图。

## 文件

- `dist/game.js`：场景、模型、渲染、碰撞、战斗、敌人、流程、输入。
- `dist/data.js`：武器、区域、祝福、界面图标。
- `dist/index.html` / `style.css`：中文 HUD、营地与奖励界面、窄屏适配。
- `dist/vendor/three.module.js`：Three.js 0.160.1；许可证见同目录。

本地存档仅保存在当前浏览器，不包含账户同步。页面通过 WebMCP 提供只读冒险状态和武器切换工具；不支持 WebMCP 的浏览器仍可完整游玩。
