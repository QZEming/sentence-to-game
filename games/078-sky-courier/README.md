# 山岚邮航 · Skybound Courier

可直接运行的 3D 热气球货运游戏。无需安装依赖，Three.js 引擎随项目提供。

## 本地游玩

```bash
npm start
```

打开 http://127.0.0.1:4173 。若端口占用，使用 `PORT=4187 npm start`。

## 操作

- Space / Shift：加热上升 / 排气下降
- A、D / W、S：转向 / 调节推进
- F：航向辅助（只负责水平航行，玩家控制高度与着陆）
- H：定高；B：抛出 10 kg 压舱沙
- E：在驿站停稳后打开交付、委托、补给与升级
- C：切换环绕 / 跟随 / 鸟瞰视角；M：完整航图；Esc：暂停
- 拖动场景旋转视角，滚轮缩放；触屏可用屏幕按钮同时控制

## 玩法

五座不同海拔的山间村落，三层风场，载重影响悬浮温度与航速。普通、易碎和限时货物，可同时装载三单。安全停泊才可交付；撞地扣除气球耐久和货物完好度。金币可补油、维修、补沙并购买三级推进器、节能燃烧器和货舱升级。首单无时限，10 分钟班次结算后可继续自由航行。支持本机自动存档、音效、救援与重开。

`npm test` 验证物理帧率一致性、载重、交付门槛、损伤、经济与完整飞行闭环。
`npm run check` 验证脚本语法。

所有场景、地形、热气球和村落均为程序化几何。外部 Google 字体不可用时自动回退系统字体。游戏需要支持 WebGL 的现代浏览器。

## 文件

- `dist/world.js`：3D 场景与模型
- `dist/simulation.js`：飞行、货运与经济模拟
- `dist/game.js`：渲染、输入、界面和存档
- `dist/index.html`、`dist/style.css`：中文驾驶界面与触屏适配
- `dist/vendor/THREE-LICENSE.txt`：引擎许可

浏览器本机存档键为 `skybound-courier-v1`。游戏未使用远程数据库。
