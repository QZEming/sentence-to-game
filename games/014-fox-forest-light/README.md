# Foxlight · 森林里的光

使用 Three.js + Vite 实现的可玩 3D 森林光线解谜游戏，全部模型由代码生成，无图片、模型或字体下载依赖。

## 启动

```bash
npm install
npm run dev -- --port 5199
```

打开 http://localhost:5199 。生产构建：`npm run build`，生成到 `dist/`。

## 玩法

- WASD / 方向键移动小狐狸，或点击地面前往；手机提供方向按钮。
- 点击镜子选中，Q / E 或界面按钮每次旋转 45°。
- 光束同时经过三枚水晶即可通关；共三关，镜子数量逐关增加至五面。
- 靠近星屑自动收集，每关五枚。通关后可以继续探索，并从任务卡继续下一关。
- 空格请求提示，R 重置本关，Esc 暂停。
- 右上角可以开启合成音效、查看帮助；森林手记随通关解锁，记录保存在浏览器本地。

## 验证

`node scripts/check-puzzles.mjs` 使用游戏实际的光线追踪函数，检查三关初始状态均未通关，预设解法均点亮三枚水晶。

已进行浏览器实际镜面旋转、目标更新和首关通关面板检查。需要支持 WebGL 的现代浏览器。
