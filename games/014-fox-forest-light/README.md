# 森光 · LUMEN FOX

一个完整可玩的浏览器 3D 森林光线解谜游戏。小狐狸「阿烁」用古镜引导晨光，唤醒月石与森林星门。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的地址，默认 http://127.0.0.1:5188/ 。

```bash
npm test       # 光学规则和全部关卡可解性测试
npm run build # 输出生产静态站点到 dist/
npm run preview
```

部署时将 `dist/` 目录交给任意静态网站服务器。游戏模型、声音和逻辑均由代码生成；字体有在线字体和系统字体回退。

## 玩法

- 点击地面移动，或按 WASD / 方向键；Shift 奔跑，Space 冲刺。
- 点击镜子选中；Q / E 或屏幕按钮每次旋转 45°。F 选择最近的镜子。
- 将光送入同色月石。所有月石同时亮起后，星门永久解锁。
- 靠近金色星屑即可收集，每关 3 枚，共 15 枚；不影响通关。
- H 获取分步提示，M 打开地图，J 查看旅途手记。
- 鼠标滚轮缩放，右键拖动环视，C 重置视角。
- Esc 暂停 / 继续，R 重置当前谜题。
- 触屏支持点击移动、方向按钮和镜面旋转按钮。
- 浏览器本地自动保存进度；设置可切换音效、画面品质和全屏。

## 五片林地

1. **苏醒林地**：单面镜子的反射入门。
2. **苔藓回廊**：三面镜子的连续反射。
3. **蓝蕨幽谷**：滤色晶片与同色月石。
4. **棱晶花园**：将晨光分为蓝光与粉光，同时点亮两颗月石。
5. **古树圣所**：四面镜子、分光棱晶和移开荆棘的月纹压力板。

## 实现

- Three.js：程序化低多边形森林、动画狐狸、柔和阴影与辉光。
- 纯 JavaScript 光线追踪：有限镜面反射、色光过滤、棱镜分支、障碍遮挡和闭环终止。
- A* 路径规划：避开石头、机关和岛屿边缘；压力板状态变化后重新寻路。
- Web Audio：程序化森林氛围、鸟鸣和交互音效，在首次用户操作后启动。
- `src/puzzles.js` 定义关卡与光学规则；`src/world.js` 生成全部 3D 模型；`src/main.js` 管理游戏、UI 与存档；`src/audio.js` 负责声音。

需要支持 WebGL 的现代浏览器。设备性能不足时可在设置中切换「流畅」画质。
