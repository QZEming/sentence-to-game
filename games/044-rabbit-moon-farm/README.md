# 月芽 Moonbloom

一个使用 Three.js 的中文 3D 月球农场游戏。静态文件均位于 `dist/`，不需要构建。

运行：`python3 -m http.server 8765 --directory dist`，打开 http://localhost:8765。

玩法：点击空地种植；数字 1–4 切换农具；点击成熟作物收获；背包出售；星野探索获得月晶石，工坊研究永久升级。拖拽旋转，滚轮缩放，Q/E 转动视角，B 打开背包，空格暂停，Esc 关闭面板。

包含 6 种作物、16 块可解锁地块、5 个任务、4 项研究、2 个探索区域、6 个奇遇、等级解锁、3 种天气、昼夜计时、程序生成的环境音乐和设备本地自动存档。离线时游戏不推进。无需后端、登录或 API 密钥。

核心渲染库 Three.js 0.169.0（MIT）保存在 dist/vendor/three.js。界面字体加载失败时使用系统字体。
