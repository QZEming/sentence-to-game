# 喵叠叠 · 小猫的天空工坊

Three.js + Vite 的独立 3D 浏览器游戏。全部场景、积木、小猫与装饰均由代码建模，无需外部图片或字体。

## 运行

```sh
npm install
npm run dev
```

打开终端输出的本地地址。生产构建：`npm run build`；预览产物：`npm run preview`。

## 玩法

- 空格 / 放下积木按钮：抓准中心放置。积木交替沿 X、Z 轴移动。
- R：旋转积木；P：暂停；拖动场景 / 箭头：环绕镜头。
- 完美叠放增加连击、得分与鱼干。积木尺寸会周期变化。
- 支撑重叠率和累积偏心决定倒塌，稳定度条提供反馈；倒塌后可重新开始。
- 稳稳爪减轻累积偏心；慢一点魔法减速 6 秒；各每局两次。
- 经典模式目标 12 层；暴风挑战目标 16 层、风力和速度更高；自由模式不会失败。
- 首次达到目标可领取 30 鱼干并继续搭建。最高层数、鱼干存于浏览器 localStorage。
- 提供合成音效开关、移动端按钮、响应式布局和随塔高调整的镜头。

这是使用支撑率与偏心指标的街机平衡模拟，并非完整刚体物理引擎。鱼干用于记录奖励，当前没有付费或商店。

## 验证

生产构建通过。Playwright 检查放置、道具扣减、暂停恢复、旋转和模式重置。浏览器截图位于 `output/playwright/`。
