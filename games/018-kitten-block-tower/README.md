# 猫猫叠叠乐 · Cat Stack Club

一个可直接运行的中文 3D 物理搭塔游戏。Three.js 渲染、Cannon ES 刚体物理，依赖已打包在本地，无需 npm 安装。

## 本地运行

```bash
cd cat-stack
python3 -m http.server 5188 --directory dist
```

然后打开 http://localhost:5188 。需要支持 WebGL 的现代浏览器。

## 玩法

- **经典搭塔**：目标 20 层，速度随层数增加。
- **悠闲时光**：无限层数、较慢速度、没有风、2 次接住落空积木的机会。
- **暴风挑战**：90 秒内挑战 20 层，每 12 秒一阵侧风，提前 2 秒预告。
- 六种积木，包含易滑冰块、重石、长条木块；不同尺寸、质量和摩擦力。
- 精准落点提供连续加分，3 次连击奖励一次慢动作。
- 猫爪扶正最顶层积木；慢动作将移动速度降低 5 秒。
- 几何小猫动画、粒子庆祝、可选合成音效；最高层数按模式保存在当前浏览器。

键盘：空格投放，R 旋转，A/D 或左右键微调，Q 扶正，E 慢动作，P 暂停。支持触控按钮、拖动旋转视角、滚轮缩放。切换模式会重新开局。

## 验证

```bash
node --check cat-stack/dist/game.js
node cat-stack/tests/physics-smoke.mjs
```

物理烟测直接使用游戏源代码和 Cannon，覆盖 20 层通关、三种模式、连续投放屏蔽、旋转、道具、暂停、落空、悠闲补救、已计分积木倒塌与重新开局。测试不需要浏览器；画面已在桌面和 390×844 手机视口检查。

主要文件：`dist/index.html`、`dist/style.css`、`dist/game.js`。开源依赖声明位于 `dist/vendor/`。
