# 午夜爪印 · Midnight Paws

一个中文 3D 猫咪博物馆潜入策划游戏。Three.js 已随项目提供，无需安装依赖。字体使用在线字体，断网时自动回退系统字体；游戏逻辑与三维资源均可离线运行。

## 启动

在此目录执行 `npm start`，访问 http://127.0.0.1:4187 。需要 Python 3；不要直接以 file:// 打开 HTML，因为浏览器会阻止 ES 模块加载。

## 玩法

- 点击地面布置路线，空格开始 / 暂停策划。路线按节点直线移动，需要自行绕开障碍。
- WASD / 方向键接管移动，Shift 悄行，E 与附近目标交互。触屏可点击地面移动，并使用靠近目标后出现的交互按钮。
- 任务链：西翼门禁卡 → 东翼安保终端 → 中央月之泪 → 绿色入口撤离。
- 守卫巡逻并使用扇形视野检测，墙体和展台遮挡视线；近距离奔跑会暴露。暴露达到 100% 失败。
- 激光周期性启停，关闭安保后永久失效。
- 1 使用烟雾弹（2 次 / 5 秒隐身）；2 使用发条老鼠（3 次 / 6 秒诱导）；3 显隐安保范围。
- 收集额外宝石获得加分。用时、最高暴露、道具使用会影响评分；最佳成绩仅保存在当前浏览器。
- 滚轮缩放、拖动旋转，视角按钮切换俯视。三种难度调节巡逻速度和警觉速度。

## 验证

`npm run check` 检查 JavaScript 语法。已在浏览器确认三维画面、开始 / 暂停、烟雾弹计数、重置、地面路线添加、障碍拒绝、自动移动和守卫暴露判定；WebMCP 状态读取与非法输入拒绝均已验证。未做完整自动通关验证。

## 文件

- dist/index.html：中文游戏界面
- dist/style.css：自适应布局
- dist/game.js：三维场景、输入、路线、巡逻、碰撞、任务、道具和评分
- dist/vendor/three.module.js：Three.js 0.170.0（MIT）

仅支持具备 WebGL 的现代浏览器。当前交付为本地可运行版本；执行环境缺少 Sites 的发布脚本，未部署线上地址。
