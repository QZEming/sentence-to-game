# 鸦林疑案 · Ravenwood

使用 Three.js 与 Vite 实现的中文 3D 森林推理游戏，无需后端。

## 运行

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5188
```

生产构建：`npm run build`，静态产物在 `dist/`。预览构建：`npm run preview`。

## 玩法

- WASD / 方向键移动；点击地面移动，点击线索标签自动前往调查。
- 拖动旋转镜头，滚轮缩放。
- E 调查附近物品或人物，Q 使用鸦之视野寻找最近未收集线索。
- F 切换低空飞行，可加速并越过河流。步行需要经过桥梁。
- J 打开线索手册，R 打开推理板，M 打开可点击导航地图。
- Esc 关闭面板或暂停；右上角开启环境音与操作指引。
- 收集至少四条线索并完成三步推理，再破解矿井密码，救出守林人。
- 六条线索包含物证、足迹、两位居民证词和密码提示；全收集可取得更高评价。
- 进度保存在当前浏览器 localStorage；通关后可漫游或重新调查。
- 移动端提供屏幕方向键与触控功能。

场景、角色、树木、营地、矿井、河流、桥梁及音效均由代码生成。Google Fonts 为可选字体，无法联网时自动使用系统字体。需要支持 WebGL 的现代浏览器。

## 验证

已通过 `node --check src/main.js`、`npm run build`。在本地浏览器完成物证收集、居民证词、三步推理、矿井密码和通关流程验证。
