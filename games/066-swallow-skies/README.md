# 燕尾中队 · Swallow Skies

一个使用 Three.js 的中文 3D 街机空战游戏。燕子飞行员驾驶双翼机守护海岛，对抗海盗巡逻机、截击机、轰炸机与黑帆舰长的飞艇。

## 运行

要求 Node.js 18+。3D 引擎已经随静态站点打包，本地运行不需要下载依赖。

```sh
npm start
```

打开 http://127.0.0.1:5187 。`dist/` 可直接部署到静态托管服务；请通过 HTTP 访问，而非双击 HTML。

## 玩法

- 五波战役，通关后继续无尽模式，后续波次提高难度。
- 自由转向、升降、机枪辅助瞄准、追踪导弹、翻滚无敌与能量加速。
- 三类海盗敌机；飞艇首领具有扇形弹幕与护航机。
- 连击倍率、三环航线挑战、可吸附的维修／护盾／导弹补给。
- 八种升级中每波随机三选一；选择期间暂停战斗。
- 三架可解锁飞机、两档难度、六枚成就徽章与本地最高分。
- 程序合成音效、暂停、全屏、鼠标和触屏摇杆支持。
- 金币、机库解锁、成就、偏好仅保存于当前浏览器；没有账号或跨设备同步。

## 操作

| 按键 | 动作 |
| --- | --- |
| W / S 或 ↑ / ↓ | 抬升 / 下降 |
| A / D 或 ← / → | 转向 |
| 空格 / 按住鼠标 | 机枪 |
| E | 锁定目标后发射导弹 |
| Q | 翻滚躲避 |
| Shift | 按住加速 |
| X | 切换锁定目标自动开火 |
| Esc / P | 暂停 / 继续 |
| M / F | 声音 / 全屏 |

鼠标模式在主菜单或飞行手册中切换。触屏使用左侧摇杆和开火、技能按钮。

## 文件

- `dist/game.js`：场景、模型、飞行、战斗、音效、任务状态机。
- `dist/ui.js`：HUD、机库、升级、结算、本地存档与可选 WebMCP 注册。
- `dist/style.css`：响应式界面。
- `dist/vendor/`：本地 Three.js 0.180.0 与 MIT 许可证。
- `server.mjs`：本地静态预览。

## 验证

桌面与手机视口已检查。截图位于本地 `output/playwright/`（不发布）。WebMCP 为可选能力，未支持该 API 的浏览器不注册工具；不影响游戏。
