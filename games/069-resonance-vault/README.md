# 回响 · RESONANCE VAULT

中文 3D 声音推理解谜游戏。玩家作为异常物件调查局的声学专家，聆听三件保险箱的虚构机关，解开被封存的记忆。

## 本地运行

使用静态服务器打开 `dist/`：

```bash
python3 -m http.server 43138 --bind 127.0.0.1 -d dist
```

访问 `http://127.0.0.1:43138`。无需安装依赖或构建。Three.js 已本地包含，字体不可用时会使用系统字体。声音需首次用户点击后才能启用。

## 游戏内容

- 三件独立藏品：俄耳甫斯之匣、深海潮汐钟、月背来信。
- 每件藏品包含机械锁芯、共振密钥、记忆回响三层机关。
- 可旋转、缩放、聚焦的真实 WebGL 场景、可拖动锁盘与开启动画。
- Web Audio 实时合成锁芯双击、共振拍频与旋律；实时示波器、增益和音色滤波。
- 听诊、观察、敲击三种工具，专家笔记、渐进提示、结局故事与 S/A/B 评级。
- 当前浏览器自动存档、独立档案进度、手机布局、键盘操作、静音和视觉辅助。
- WebGL 不可用时保留完整操作面板；声音不可用时可通过视觉辅助游玩。

## 操作

拖动空白处观察保险箱；滚轮缩放。使用滑杆、加减按钮或左右方向键精细调整；Shift 加速。空格开启/暂停聆听，Enter 确认，1/2/3 切换工具，A/S/D 输入低/中/高音，? 打开手册。

旋律只要求音高顺序正确，无抢拍要求。失误保留已完成机关；视觉辅助与重听不影响评级。

## 检查

```bash
npm run check
```

包含 JavaScript 语法检查、角度环绕边界、全部关卡可达性和评级边界测试。浏览器实际验证覆盖三关完整通关、错误旋律重试、存档恢复与 390px 手机布局。

## 文件

- `dist/game.js`：交互、音频、状态管理和浏览器工具接口。
- `dist/scene.js`：Three.js 场景与保险箱模型。
- `dist/puzzles.js`：谜题参数与纯规则函数。
- `dist/style.css`：响应式工作台界面。
- `dist/vendor/`：本地 Three.js 与 MIT 许可证。

游戏所有机关均为虚构设计，不模拟实际保险箱开锁技术。
