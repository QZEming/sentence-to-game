# 巨兽禁区 · TITAN ZERO

浏览器运行的单人 3D 城市破坏沙盒。以 Three.js 实时渲染低多边形城市、巨兽与防卫队，不依赖外部模型服务。

## 运行

在本目录执行 `npm start`，然后访问 `http://localhost:4173`。无需安装依赖；Three.js 已随项目分发。

## 玩法

- **生存挑战**：五分钟内争取最高分，结束后可继续无尽模式。
- **自由沙盒**：默认无敌与无限能量，可切换防卫军增援、锁定警戒等级、召唤机甲或重建城市。
- **攻击**：重拳、地裂践踏、原子吐息、残骸/车辆投掷、冲撞、核能暴走。
- **破坏**：88 栋可破坏建筑、倾倒残骸、车辆、燃料罐连锁爆炸、能量和生命掉落。
- **敌人**：坦克、直升机、重装机甲；炮火会预警并能损坏建筑。
- **成长**：六个连续目标、连击倍率、进化三选一、最高分本地保存。
- **控制**：键盘鼠标；触屏摇杆与技能按钮、自动瞄准。

## 项目结构

- `dist/index.html`：游戏界面与入口。
- `dist/style.css`：响应式界面。
- `dist/game.js`：场景、战斗、AI、成长、音效、输入与主循环。
- `dist/vendor/three.module.js`：Three.js 0.170.0，MIT 许可。
- `.openai/hosting.json`：静态站点发布配置。

验证语法：`npm run check`。`window.titanState()` 提供只读游戏遥测，便于自动化验收。

## 说明

需要支持 WebGL 的现代浏览器。重型场景性能取决于设备，触屏设备自动降低渲染分辨率并关闭实时阴影。破坏和残骸使用自定义街机式模拟；没有联网多人功能。最高分仅存储在当前浏览器。
