# 双生神殿 · EIDOLON

可在浏览器直接游玩的 3D 双角色协作解谜游戏。原生 Three.js 渲染，核心依赖随游戏一起提供，无服务器游戏逻辑。

## 玩法

- 曦（光之灵）：通过金色光桥、点亮光属性晶柱。
- 晦（影之灵）：穿过蓝色影障、唤醒影属性晶柱。
- `Q` 交换两个身体中的灵魂与能力，身体位置保持不变。交换需要两具身体都在安全石台上。
- 神殿机关一旦点亮就永久开启。最终让两个角色同时站上匹配的光影祭坛。

三座关卡依次引入属性转换、彼岸交叉开门、三轮同步换魂。另有九枚可收集记忆碎片、逐步提示、合成音效、暂停、镜头缩放和关卡重玩。收集、最佳成绩和解锁进度仅保存在当前浏览器。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 / 点击地面 |
| 切换身体 | Tab / 1 / 2 / 底部角色卡 |
| 交换灵魂 | Q / 底部双向按钮 |
| 晶柱共鸣 | E / 空格 / 点击相邻晶柱 |
| 逐步提示 | H / 左侧提示按钮 |
| 暂停 | Esc / 右上角暂停 |
| 重置当前关卡 | R / 右下角重置 |

手机支持点击地面寻路、屏幕方向键、换魂和共鸣按钮。声音需手动开启。

## 本地运行

```sh
npm start
```

打开 `http://localhost:4173`。需要 Python 3；不需要 npm 安装。`dist/` 也可以由任何静态服务器托管。

```sh
npm test
```

逻辑验证覆盖三个完整通关解法（分别 2、1、3 次灵魂交换）、互斥地形、错误属性、永久开门、安全交换、收集去重、关卡重置和全部记忆放置。

## 文件

- `dist/game.js`：3D 场景、输入、动画、声音、界面、保存与可选 WebMCP。
- `dist/logic.mjs`：可独立验证的关卡数据、路径搜索、机关和通关判定。
- `dist/style.css` / `dist/index.html`：响应式游戏界面。
- `dist/vendor/three.module.js`：Three.js r170，MIT 许可。
- `test/logic.test.mjs`：关卡与规则回归验证。

WebGL 是运行条件。浏览器不支持 WebGL 时会显示明确提示。WebMCP 是可选增强，浏览器未实现该接口时常规游戏完全可用。
