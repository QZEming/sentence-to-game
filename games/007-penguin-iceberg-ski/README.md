# 冰川疾行 · Penguin Alpine

无需构建的 Three.js 3D 滑雪游戏。Three.js 已随项目提供，无需 CDN 连接即可游玩（在线字体失败时使用系统字体）。

## 本地运行

```sh
python3 -m http.server 4187 --directory dist
```

打开 http://localhost:4187 。不要直接通过 file:// 打开 ES module。

## 玩法

- 无尽远征：三颗心，随里程提高速度，挑战个人最佳。
- 极地竞速：90 秒内争取最高分，仍需注意三颗心。
- 自由漫游：不会受伤，适合熟悉地图和欣赏风景。
- A/D 或左右方向键转向；空格二段跳；Shift 消耗能量冲刺；F 空中翻转；P/Esc 暂停。
- 触屏设备提供左右、冲刺、翻转、跳跃按钮。
- 鱼群提高连击，三秒内连续收集；每五连击提高倍率，最高五倍。
- 跳台自动腾空；空中成功翻转奖励 300 分与能量；过早落地不会发放奖励。
- 冰块与裂隙扣一颗心并短暂无敌；护盾挡一次撞击；磁铁吸引附近小鱼。
- 五个渐进任务；每 750 米切换蔚蓝冰川、日落峡谷、极光雪原。
- 个人最佳仅保存在设备 localStorage；音效可切换；窗口失焦自动暂停。

## 技术

静态 HTML/CSS/ES modules，Three.js r170（MIT），程序化 3D 模型和粒子。无需账号或后端。浏览器必须支持 WebGL 2。
