# 极地滑行 · Polar Drift

一个无需构建的 Three.js 3D 企鹅滑雪游戏。所有运行依赖均随项目提供，无需 CDN、账号或服务端数据库。

## 本地启动

需要 Node.js 18 或更高版本：

```sh
npm run dev
```

浏览器打开 `http://127.0.0.1:4317`。也可以用任意静态文件服务器托管 `dist/`；ES module 需要 HTTP 服务，不要直接双击 HTML。

## 操作

- 方向键或 A / D：转向；腾空时持续转向可以完成 360° 转体。
- 空格：跳跃；菜单中开始游戏。
- Shift：按住冲刺，消耗能量；收集鱼和自然恢复补充能量。
- Esc：暂停或继续。
- 手机：使用画面底部的左右、跳跃、冲刺按钮。

## 玩法

- 冰川竞速：固定种子的 2,000 米赛道，三颗心，终点结算。
- 无尽远征：不断生成的赛道，速度与障碍逐步增加并封顶。
- 自由滑行：较低速度，不扣生命，适合练习。
- 收集金色鱼群、通过旗门、使用跳台、空中转体和贴近冰柱通过均可得分。
- 连续得分触发最高 3 倍连击；碰撞或长时间无得分会失去连击。
- 蓝色晶体提供 10 秒一次性护盾，紫色晶体提供 10 秒磁铁。
- 依次完成鱼群、旗门、转体、距离目标，获得分数和冲刺能量奖励。
- 每 800 米过渡到新的天色，呈现冰川、日落、极光三种氛围。
- 四种围巾、音效开关、画质切换、本机最佳成绩；切换窗口自动暂停。

围巾与最佳成绩仅保存在当前浏览器的 localStorage 中。竞速与无尽共享本机最佳分数。

## 文件

- `dist/index.html`：中文游戏界面。
- `dist/style.css`：桌面与手机布局。
- `dist/game.js`：场景、物理、生成器、玩法与状态管理。
- `dist/vendor/`：Three.js 0.180.0 与 MIT 许可证。
- `server.mjs`：仅绑定本机地址的开发服务器。

程序化生成器为每段保留一条没有冰柱或裂隙的鱼群路线，且相邻安全路线最多横移一条通道。使用时间增量模拟，碰撞后短暂无敌，暂停冻结游戏进度。

## 检查

```sh
npm run check
```

在 Chrome 中通过实际浏览器操作检查 3D 首屏、练习模式、移动、跳跃、冲刺、暂停/恢复、重新开始和手机布局。

### 本次验证结果

- JavaScript 语法检查通过；实际 Chrome 加载无控制台错误。
- 1440×960 桌面首屏、390×844 手机菜单与游戏画面均已截图检查；见 `output/playwright/`。
- 浏览器实测转向、跳跃和 360° 转体得分、冲刺耗能、暂停冻结、触屏转向/跳跃，以及重开重置。
- 实际游戏函数的内存回归覆盖竞速成功/失败、一次性护盾、磁铁收集、防止重复计分、练习不扣心、固定随机种子和安全路线。
- 安全路线模拟：76.77 秒完成 2,000 米，保留 3 心，收集 166 条鱼，穿过 19 道旗门。
- 20 FPS 与 60 FPS 使用相同物理子步，两秒距离均约 44.124690 米，转体与得分一致。

本机服务器运行期间可直接打开上述地址；关闭后重新运行 `npm run dev` 即可。
