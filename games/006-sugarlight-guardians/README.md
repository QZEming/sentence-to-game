# 星绒守夜队

一款原创、可静态部署的 3D 塔防小游戏。你是月芽花园的新任守夜队长，带领星弹兔、薄荷猫、蜜糖熊和灯笼啾，守住月芽树上的最后一颗梦种。故事、美术模型、界面与音效均在这个新目录内独立制作；原始创意需求保存在 `prompt.txt`。

## 运行与构建

需要 Node.js 20.19+ 或 22.12+；本项目已在 Node.js 24 与 Chromium 中验证。

```sh
npm ci --cache /tmp/starfluff-npm-cache
npm run dev -- --port 5173
npm test
npm run build
npm run preview -- --port 4173
```

构建产物为 `dist/index.html` 与相对路径资源。把整个 `dist/` 部署到任意静态网站子目录即可，无服务器 API、外部字体、在线图片或运行时 CDN。浏览器需要支持 WebGL 2。Three.js 的 MIT 许可证随构建一起保存在 `dist/licenses/`。

## 怎么玩

1. 点击下方守卫卡，再点击花园里的圆形空地建造；也可以先选空地、再选守卫。
2. 点击“开始守夜”开始一波。让梦魇走到终点会扣除梦种生命，生命归零则失败。
3. 点击已建守卫查看射程、升级或出售。每位守卫最多三级，出售返还总投入的 72%。
4. 灵活搭配：星弹兔持续输出、薄荷猫减速、蜜糖熊范围爆破、灯笼啾在战斗中产出星露。
5. 每过三波选择一次全队祝福；第十二波迎战噩梦毛球王。守护更多生命会获得更高星级。
6. 三个主动技能有独立冷却：流星雨打击全场、晚安泡泡冻结四秒、月芽祝福恢复三点生命。

鼠标或触控都能完成操作。快捷键：`1–4` 选择守卫；`Q / W / E` 释放技能；`空格` 开始波次或暂停；`P` 暂停；`F` 切换一/二/三倍速；`M` 开关声音；`Esc` 取消选择。首次点击声音按钮后启用 Web Audio 合成音乐与音效。切到后台会自动暂停。通关最高星级只存储在当前浏览器。

## 内容与验证

- 十二波递进挑战、四段原创故事、五种敌人（含首领）、四种可升级守卫。
- 三次三选一祝福、三种主动技能、完美波奖励、暂停/倍速/重开、移动端自适应界面。
- `npm test` 验证路线、建造两种流程、经济/升级/出售、暂停与倍速、技能限制、冻结、整波结算、失败和祝福。
- `tests/browser_smoke.py` 以真实 Chromium 验证页面加载、建造、升级、技能、暂停、倍速、窄屏布局以及子目录部署。

游戏逻辑位于 `src/game.js`，角色和场景为 Three.js 程序化模型，界面不依赖前端组件框架。`window.__STARFLUFF__` 仅提供只读状态快照与地块屏幕坐标，供浏览器验证使用。
