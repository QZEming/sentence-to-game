# 异星潜伏 · XENOVOID

可直接运行的中文单人 3D 社交推理游戏。Three.js 已随项目分发，无构建步骤、无 API 密钥、无后端依赖。

## 本地运行

```bash
python3 -m http.server 4186 --directory dist
```

打开 http://localhost:4186 。浏览器需要支持 WebGL。

## 操作

- WASD / 方向键移动；点击地面或任务条目自动寻路。
- E 操作舱室控制台，R 召开紧急会议，M 打开调查笔记，Esc 暂停。
- 点击船员询问行踪和目击；在会议中出示线索，再选择投票或弃票。
- 手机提供方向键、交互按钮及顶部笔记入口。

## 玩法

7 个舱室、8 名船员、每局随机的 1 名外星伪装者；6 项个人维护任务，涵盖配线、扫描时机、顺序记忆、输出校准、物资归档。AI 依据实际路线、目击和公开证据讨论投票；伪装者会撒谎、通风管转移、袭击 AI 船员、破坏供氧。会议和所有弹窗暂停模拟。两次紧急会议，尸体报告不消耗会议次数。

驱逐伪装者或完成 6 项个人与 4 项 AI 维护获胜；氧气耗尽、玩家被错误驱逐或船员人数降至 1 人时失败。玩家不会被突然袭击；单人玩法重点为调查、团队保护与决策。

标准 / 危机难度调整袭击和供氧压力。含音效开关、暂停、视角缩放与旋转、游戏结束后的真相复盘。

## 验证

```bash
node --experimental-default-type=module tests/game.test.mjs
```

覆盖身份分配、任务位置及防重复、事件与证据对应、会议冻结、证据去重、投票结算、冷却、修复和两种终局。已在真实浏览器验证 WebGL 场景、启航、自动寻路、配线任务及会议证据和胜利结算。

## 文件

- `dist/game.js`：模拟状态、任务、事件、证据、会议与胜负
- `dist/world.js`：3D 飞船、船员、寻路和交互
- `dist/app.js`：游戏界面、任务小游戏和 WebMCP 公开操作
- `dist/style.css`：桌面和手机布局
- `dist/vendor/`：Three.js 0.180.0 及其 MIT 许可证

Google Fonts 为可选字体资源；无法联网时回退至系统字体。核心游戏资源均为本地文件。
