# 深时档案 · Fossil Expedition

中文 3D 考古拼装游戏。Three.js 0.180.0 与 OrbitControls 已随站点本地打包，游戏无需安装依赖或连接后端；使用支持 WebGL 2 的现代浏览器。

## 游玩内容

- 三处逐步解锁的遗址：红岩峡谷、琥珀荒原、蕨林盆地。
- 三种独立的程序化骨架：三角龙、霸王龙、剑龙，各有六组骨骼部件。
- 四种考察工具：地质锤、精细凿、软毛刷、探测器；分层清除土壤，显示实体骨骼。
- 完整度损伤、体力消耗、免费营地休整、研究经费、三级工具升级。
- 修复实验室：每件标本有五处独立泥块，支持在模型上刷除，也支持按钮操作。
- 骨架拼装：选择部件、旋转方向、点击对应轮廓拼合；按钮作为触屏和键盘操作的替代路径。
- 博物馆展陈、古生物图鉴、五项成就、独立展品收藏。
- 相机旋转/缩放/复位、纯净观赏模式、可开关音效、手机布局、键盘快捷键。
- 进度自动保存到当前浏览器 localStorage，加载时校验数据；清空进度需再次确认。

## 本地运行

```sh
npm start
```

打开 `http://127.0.0.1:8473`。静态服务根目录为 `dist/`，不能通过直接双击 HTML 的 `file://` 协议运行 ES 模块。

```sh
npm test
```

无需安装 npm 依赖。`package.json` 仅提供本地运行和测试脚本。

## 操作

点击 3D 地块发掘；拖动空白处旋转视角；滚轮或右侧加减按钮缩放。土层清除至 60% 后建议改用软毛刷，完整度影响最终奖励。

`1–4` 切换工具，`←/→` 选择部件，`空格` 执行当前操作，`R` 旋转待拼装部件，`E` 进入实验室，`?` 打开指南。修复台拖动清理时锁定相机旋转。

## 验收

- 核心自动测试：210 次操作完成三个物种的发掘、清理、拼装和一次性奖励；涵盖体力不足、错误操作、粗工具损伤、存档还原、损坏存档校验。
- 真实 Chromium 页面验收：3D 射线拾取、六件标本出土、刷新恢复存档、三十处清理点、旋转方向校验、六个部件拼合、入馆、下一遗址解锁、购买升级、休整、音效、帮助弹窗和手机无横向溢出。
- 控制台无 JavaScript 运行错误。桌面及移动截图保存在 `output/playwright/`（不发布）。
- 另外为支持 WebMCP 的浏览器提供三个工具。验收浏览器未提供 `document.modelContext`，因此该可选接口未做受支持环境验证；不影响普通游玩。

## 文件

`dist/index.html` 界面结构；`dist/style.css` 样式；`dist/game.js` 玩法状态机；`dist/scene.js` 3D 模型和场景；`dist/app.js` 交互与存档；`test-game.mjs` 核心测试。

遗址名称和考察坐标用于虚构游戏世界，骨架为便于玩法而设计的简化复原。科普内容链接至伦敦自然历史博物馆。Three.js 使用 MIT 许可，许可全文见 `dist/vendor/LICENSE-three.txt`。
