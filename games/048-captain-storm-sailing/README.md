# 风暴小船长 · Storm Captain

无需构建的 Three.js 3D 航海游戏。Three.js 已随源码本地打包。

## 运行

在本目录运行 `python3 -m http.server 4189 --directory dist`，打开 `http://localhost:4189`。

## 玩法

- A / D 或左右方向键：掌舵；W / S 或上下方向键：升降主帆。
- 空格：放下/收起海锚；R：消耗 1 木材修复 25% 船体。
- M：航海图；C：切换跟随、俯瞰、船长镜头；P / Esc：暂停。
- 依次抵达四个金色航标，收集补给，救援两名落水船员。
- 强风下主帆超过 60% 会缓慢损伤船体；碰撞岛礁造成即时伤害。
- 触屏可使用屏幕舵向按钮、帆面滑杆、修复及暂停按钮。

## 实现

叠加波浪高度场、弹簧阻尼浮力、海面坡度俯仰与横摇、风向效率、帆面积推力、二次阻力、舵效、海锚阻力、岛礁碰撞与资源修复。采用可玩性导向的近似物理，不是工程级船舶流体仿真。没有账号、联网对战或云存档。

## 验证

- `node --check dist/game.js` 通过。
- 在本地浏览器验证 WebGL 渲染、启航加速、自动补给收集、航海图暂停；控制台无错误。
- WebMCP 状态查询及主帆设定 0.45 成功；越界值 2 被拒绝且不改变主帆。
