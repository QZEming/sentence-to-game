# 群岛使者 · Envoy of the Tides

浏览器单人 3D 外交策略游戏。操纵一艘中立使船穿梭于五个王国，在 24 回合内联合至少四国并取得 65 声望；危机达到 100 或远征逾期则失败。

## 运行

```sh
cd archipelago
python3 -m http.server 4277 --bind 127.0.0.1 --directory dist
```

浏览器打开 `http://127.0.0.1:4277`。所有游戏代码与 Three.js 依赖均在 `dist/` 内，不需要构建或安装依赖。谷歌字体不可用时会自动使用系统中文字体。3D 需要 WebGL；不可用时外交界面仍可完整游玩。

## 已实现玩法

- 可旋转、缩放、点击的立体群岛，五种王国建筑、航线、使船航行动画、动态海水与海鸟。
- 五个独立外交档案、关系值、领袖诉求和结盟特权。
- 每轮三次行动；金币、补给、声望与风暴危机的联动经济。
- 互惠贸易、共同防御、知识交流、和平调停四种谈判立场。
- 情报、附赠金币、偏好、失败重试和敌对王国联盟共同影响接受概率。
- 通商协定、正式联盟、一次性王国委托、赠礼、整备、和平演说与争端调停。
- 六个有分支选择的事件、24 回合限制、明确胜负结局与新远征。
- 自动存档、存档导入/导出、联盟议会、航海日志、可选环境音和游戏手册。
- 手机适配、原生可键盘操作对话框、WebMCP 读取/选择/行动接口。

新远征会生成随机种子；存档保留种子和随机数进度，刷新不会重掷谈判结果。事件总有免费暂缓选项，整备不需要资源，从而避免软锁。

## 验证

```sh
node --test tests/game.test.mjs
node --check dist/app.mjs
node --check dist/world.mjs
```

已验证完整胜利路线、无效行动原子性、耗尽资源后的恢复、事件退出、重复奖励保护、行动力、概率加成、危机与截止失败。浏览器实测包含航行、委托、谈判失败和成功、事件结算、刷新恢复；390×844 移动断点无页面横向溢出。WebMCP 已验证正常执行与非法行动拒绝。

## 结构

- `dist/game.mjs`：独立、可测试的游戏状态与规则。
- `dist/world.mjs`：Three.js 场景与相机交互。
- `dist/app.mjs`：界面、存档、对话框、WebMCP。
- `dist/styles.css`：桌面与移动布局。
- `dist/vendor/`：Three.js 0.160.1 及 OrbitControls，MIT 协议。

存档保存在浏览器本地，不包含账户、联网对战或跨设备云同步。
