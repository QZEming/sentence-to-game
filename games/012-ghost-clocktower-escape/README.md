# 幽时 · Hollow Hour

一个不依赖后端的 Three.js 3D 钟楼密室逃脱游戏。

## 启动

在项目目录运行 `python3 -m http.server 4173 --directory dist`，访问 `http://localhost:4173`。Three.js 已随源码打包，无需 npm 安装。请通过 HTTP 打开，浏览器的 ES 模块不能直接从 file:// 加载。

## 内容

三层可往返的钟楼、三个主线谜题和一个最终钟盘谜题、9 枚记忆、双结局文本、幽灵穿墙、灵视、巡逻守卫、合成音效、三级提示、暂停、当前浏览器自动存档、鼠标点选移动、可旋转缩放的 3D 场景、移动端虚拟摇杆。

- WASD / 方向键：移动
- E：交互
- 空格 / Shift：穿墙冲刺
- Q：灵视
- J：手记
- Esc / P：暂停或关闭面板
- 拖动 / 滚轮：旋转 / 缩放

## 通关解法

1. 藏书室宝匣：月亮、羽毛、钟声。
2. 齿轮机关：复位后 A、B 各一次，得到 ↑ ↓ ↑。
3. 钟楼旋律：低、高、中、高。
4. 最终钟盘：11:55。进入新出现的星光之门并交互。

收集记忆不阻塞主线。第三层通关后可以继续收集，九枚记忆会解锁完整结尾。存档仅保存在本设备浏览器 localStorage。

## 资源

Three.js 0.170.0（MIT），随包本地提供。场景和角色均由实时三维几何构建，音效使用 Web Audio 合成。字体使用 Google Fonts，并提供本地系统字体回退。
