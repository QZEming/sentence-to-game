# MORPH · 史莱姆实验室

可直接在浏览器中游玩的 3D 形态变化解谜游戏。使用原生 JavaScript 与 Three.js r170，全部 3D 场景由游戏实时渲染。核心运行不依赖外部 CDN；可选字体加载失败时使用本机字体。

## 本地运行

在本目录执行 `npm start`，打开 http://localhost:4173 。需要 Python 3。也可以用任意静态 HTTP 服务器托管 `dist/`。

## 操作

- WASD / 方向键：相对镜头移动。
- 1 原生：包裹与搬运能量方块。
- 2 扁平：钻过低矮横缝，在水面漂浮。
- 3 细长：穿过狭窄竖缝，触及高处开关。
- E：包裹、放下方块或触发附近的高处开关。
- 空格：弹跃加速；不会跳过封闭的墙壁与机关。
- H：分步提示；R：重新实验；ESC：暂停。
- 拖动画面旋转镜头，滚轮缩放。手机提供方向与弹跃按钮。

## 五个实验

1. 柔软的开始：基本移动、晶体与低矮横缝。
2. 向上生长：扁平漂浮、横缝与细长竖缝。
3. 温柔的力量：包裹方块，为压力底座持续供能。
4. 迂回的智慧：侧室回路、间歇激光、高处安全开关。
5. 无限的可能：琥珀与紫色双回路，结合全部变形能力。

每关收齐晶体后进入传送门完成。满足限时与零失误条件可得三星。所有关卡可自由选择；完成记录与最佳时间保存在当前浏览器的本机存储。

## 验证

`npm run check` 检查语法。`npm test` 在无渲染器的环境中执行实际游戏逻辑，覆盖地图结构、两种通道的连续碰撞、携带限制、底座吸附后不困住玩家、能量回路、目标可达性、收集、过关、本机记录、暂停、水面安全与闭门保护。

3D 渲染需要支持 WebGL 的浏览器。触屏设备建议横屏以获得更大的游戏区域。
