# BENEATH · 地心漫游

一个由 Three.js 构建的完整 3D 地下迷宫游戏。扮演戴矿灯的鼹鼠莫里，探索苔光洞穴，搜集晶石和远古遗物，唤醒通向下一层的石门。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

访问终端显示的本地地址。生成发布文件：`npm run build`，本地查看发布版本：`npm run preview`。

## 探险规则

- 每层包含 16 枚可收集晶石、3 件远古遗物、5 份蘑菇补给和 4 只巡游甲虫。
- 收集至少 8 枚晶石与全部 3 件遗物，然后抵达绿色石门，即可进入下一层。
- 晶石可升级行走速度、矿灯探索范围与声呐充能。消费不会减少该层已完成的收集进度。
- 褐色土墙可被挖开；坚硬岩石不可穿越。挖掘同时能震晕附近甲虫 4 秒。
- 蘑菇恢复 30 生命和 45 体力。营地会持续恢复生命与体力，且能保护角色免受甲虫攻击。
- 冲刺和挖掘消耗体力；步行与休息会恢复体力。
- 每层使用不同的确定性迷宫种子，深层甲虫移动更快。
- 进度自动保存在浏览器本地，包括关卡、位置、收集品、已挖通道、地图和装备。完成一层后刷新，会继续进入下一层。

所有模型、粒子和音效都由代码生成，无外部图像、字体或音频请求。游戏需要支持 WebGL 2 的浏览器。

## 项目结构

- `src/main.js`：游戏循环、移动、寻路、碰撞、敌人行为、关卡与存档。
- `src/world.js`：迷宫生成、3D 场景、角色与道具建模。
- `src/ui.js`、`src/style.css`：游戏界面、地图、装备与帮助窗口。
- `src/audio.js`：Web Audio 合成音效。

开发模式提供只读状态快照 `window.__BENEATH__.snapshot()`，方便调试。生产构建不会包含这个调试接口。

## 验证

运行 `npm test` 检查 20 个迷宫种子的边界、全路径连通性、道具数量与位置、稳定生成和场景资源释放；运行 `npm run build` 验证发布构建。
