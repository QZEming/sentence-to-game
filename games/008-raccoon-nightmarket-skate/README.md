# Rooftop Rascal · 浣熊夜行

原创 Three.js 3D 滑板小游戏。浣熊麻薯穿过灯笼巷、拉面街和霓虹天台，在无限生成的夜市屋顶上收集宵夜、翻板、滑杆、闪避障碍。

## 运行

```sh
npm start
```

打开 `http://localhost:4173`。端口占用时可使用 `python3 -m http.server 4187 --directory dist`。

静态网页，无需安装依赖或构建。Three.js 0.180.0 及其许可证在 `dist/vendor/`；字体使用 Google Fonts，加载失败时使用系统字体。需要支持 WebGL 2 的现代浏览器。

## 操作

- A / D 或左右方向键：换道。
- 空格 / W / 上方向键：跳跃；在空中再按一次翻板，安全落地得分。
- S / 下方向键：按住俯身，躲避低横梁。
- Shift：消耗 50 能量，获得 4 秒无敌加速。
- 跃上青色栏杆自动滑行；跳跃或换道离轨。
- P / Esc：暂停与继续。切换窗口或标签页会自动暂停。
- 手机支持左右/上/下滑动以及屏幕按钮。

拉面补充 20 能量；金币补充少量能量并计分；磁铁自动吸取 10 秒内附近的金币。连续动作可提高倍率至 ×8。连续收集、翻板落地和滑杆累计构成本局三个任务，每个任务奖励 1,000 分。

夜市漫游有三次机会、逐渐提速；限时挑战最长 120 秒；自由练习无限机会且保持舒适速度。漫游与限时挑战的个人最佳分数保存在当前浏览器本地；练习不覆盖纪录。音效和原创合成节拍由右上角声音按钮开启。

## 验证

```sh
npm run check
npm test
```

12 项 Node 逻辑检查覆盖换道边界、单次翻板结算、暂停、冲刺保护、收集防重、生命/练习模式、重开、倒计时、可通行路线、栏杆判定与屋顶缺口。浏览器已实测桌面和手机布局、键盘/触摸按钮、帮助面板与暂停恢复。

文件结构：`dist/engine.js` 负责独立玩法逻辑，`dist/game.js` 负责 3D 场景、声音和交互，`dist/style.css` 负责响应式界面。地图根据街区序号确定性生成，并循环回收远处场景。建筑与灯笼使用实例化渲染降低绘制开销。
