# 浮光 LUMEN

一个无需后端的中文 Three.js 3D 水母生存游戏。所有模型、粒子、水下光线与音效均由代码实时生成；渲染库已随项目保存，不依赖外部 CDN。

## 本地运行

```sh
python3 -m http.server 4182 --bind 127.0.0.1 --directory dist
```

访问 `http://127.0.0.1:4182`。需支持 WebGL 2 的现代浏览器。

## 操作

- WASD / 方向键：水平移动
- Q / E：下潜 / 上浮
- Shift：按住冲刺，消耗能量
- Space：生物电击，眩晕附近敌人
- C：在海草附近切换隐匿
- Esc：暂停 / 继续；升级时按 1、2、3 选择进化
- 手机：虚拟摇杆、潜浮按钮、技能按钮

## 玩法

- 生存远航：存活 180 秒即获胜；自在漫游：无伤害、无时间限制。
- 三类捕食者：鲨鱼缓慢转向追踪、海鳗预警突进、狮子鱼近身威胁。
- 金色光点用于升级并提供轻微治疗；连续采集加分。
- 五种进化：速度、能量、电击、吸附、自愈，每次随机三选一。
- 蓝色补能、粉色疗伤；海草隐匿会降低速度并解除追踪。
- 三个信标，接近并停留三秒可点亮、疗伤和加分。
- 雷达、深度标尺、信标方向提示、伤害反馈和结算成就。
- 标签页失焦自动暂停；最高分只保存在当前浏览器。
- 高清 / 流畅画质切换；可选程序合成海底音效。

`dist/index.html` 界面；`dist/style.css` 样式；`dist/game.js` 场景、交互与游戏逻辑；`dist/vendor/three.module.js` Three.js r170（MIT，许可证同目录）。
