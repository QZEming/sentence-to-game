# 幽蓝 · 水母远行

无需安装依赖的 Three.js 3D 海底生存游戏。Three.js 已保存在本地，字体不可用时自动使用系统字体。

## 运行

需要 Node.js 18 或更高版本。在本目录执行 `npm start`，打开 http://127.0.0.1:4173 。不要直接以 file:// 打开 HTML；浏览器会阻止 ES Module。

## 玩法

- WASD / 方向键：沿镜头方向游动；R 上浮，F 下潜。
- 拖动视角，滚轮缩放；手机使用屏幕方向按钮。
- 空格冲刺（24 能量）；Q 透明伪装（35 能量、4 秒、14 秒冷却）；E 电光脉冲（40 能量、驱散 13 米内捕食者、12 秒冷却）。
- 绿色浮游生物恢复生命、补充能量并提供成长经验。达到 6 / 16 / 30 / 50 / 75 个后进化，可选速度、吸引范围或减伤。
- 鲨鱼与海龟巡游并追击。靠近海草区且降低高度可隐蔽；被攻击后有 2 秒保护时间。
- 收集三颗金色海洋之心，返回原点海床的光环完成远行。
- Esc 暂停，离开窗口自动暂停。音效默认关闭，可点击右上角音符启用。最高分只保存在当前浏览器。

## 文件

`dist/` 可部署到任何静态网站服务；`server.mjs` 提供本地预览；`npm run check` 进行语法检查。
