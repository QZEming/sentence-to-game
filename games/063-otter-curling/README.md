# 水獭冰壶俱乐部

一个可直接运行的 Three.js 3D 冰壶游戏。中文界面，支持桌面和手机浏览器。

## 运行

```bash
npm start
```

打开 http://localhost:4173 。无需安装依赖，Three.js 已保存在 `dist/vendor`，许可同目录保留。若端口被使用，可运行 `python3 -m http.server 4179 --directory dist`。

## 玩法

- 点击或拖动冰面设置目标方向与近似力度，也可用面板滑块调整。
- 方向键左右瞄准、上下调整力度，Q/E 调整旋转；空格投壶。
- 滑行时按住空格或扫冰按钮降低摩擦。本队每局共享 100 点能量。
- 标准、轻巧、重击三种冰壶有不同质量、尺寸和旋转响应。
- 人机对战、本地双人、无限练习；电脑有三个难度，使用同一物理模拟选择入营、击打或保护战术。
- 标准冰、镜面冰、侧风或每局变化。C 切换斜视、俯视、追踪镜头。
- 每队每局 4 壶，比赛共 3 局。仅最近队得分：比对方最近壶更靠近圆心的己方入营壶每颗 1 分。接触外圈有效，出界移除。得分队下局先手，空局保留顺序，最终等分为平局。

## 实现与验证

`dist/physics.js` 是独立、固定 120 Hz 的平面物理模块，`dist/app.js` 负责 3D 场景、输入、AI、比赛状态和反馈。预估轨迹与 AI 使用相同的摩擦、旋转及碰撞模拟。`npm test` 验证关键得分边界、碰撞、扫冰和 AI 合法性。

游戏设置仅保存在当前设备，刷新会开始新比赛。本地双人不需要联网；不包含在线匹配。音效可在顶部开启。浏览器需要 WebGL；使用系统字体，所有游戏资源均为本地文件。

极光背景为本项目生成资产。场景、角色、冰壶和粒子由 Three.js 实时渲染。浏览器支持 `document.modelContext` 时注册状态读取和投壶工具；不支持时正常游戏不受影响。
