# ORBITAL CARGO · 星际装箱员

基于 Three.js 的 3D 空间装填解谜游戏。旋转和摆放不同形状的行李，将有限货舱完全填满后发射。

## 玩法

- 五条航线：月球、火星、木星、土星与开普勒；货舱从 24 格增至 80 格。
- 航线任务、限时挑战和每日货单；每日货单按设备当地日期生成固定题目。
- XYZ 三轴旋转、分层定位、碰撞与边界预览、环绕视角、俯视及透视。
- 撤销、取回、重置、最多 3 次提示、积分和星级结算。
- 提示求解考虑当前布局；计算超时会提供可撤销的参考路线整理选项。
- 磁悬浮装载允许悬空摆放，无重力限制；接受任何合法满填解。
- 完成的航线成绩仅存于当前浏览器；未完成货舱不跨刷新保存。

## 操作

选行李后，拖动货舱旋转视角，移动鼠标预览位置，点击格子或“放入货舱”确认。触屏提供方向按钮。

X / Y / Z 旋转；方向键移动；PageUp / PageDown 切层；空格放置；Ctrl / Cmd + Z 撤销；H 提示；P 暂停。

## 开发

```sh
npm install --registry=https://registry.npmjs.org
npm run dev -- --port 4187 --strictPort --host 127.0.0.1
npm test
npm run build
```

输出在 dist，需支持 WebGL 的浏览器。字体无法加载时采用系统字体。
