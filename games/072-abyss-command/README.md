# 深海静默 · ABYSS COMMAND

一个使用 Three.js 构建的单人 3D 潜艇战术游戏。浏览器直接运行，中文界面，键盘和触屏滑杆均可操作。

## 开始游戏

```bash
npm start
```

打开 http://127.0.0.1:4187 。无需安装依赖或编译；Three.js 已保存在 `dist/vendor`。需要支持 WebGL 的现代浏览器；不支持 WebGL 时可用战术海图操作游戏。

点击 **启动巡航**。建议首先点击 S02 接触，按 Space 发出主动声呐，待解算达到 62% 后按 F 发射。默认任务需要击沉补给舰，然后在海图上驶向绿色撤离区。

## 三个作战任务

- **无声猎手**：补给编队破袭，击沉补给舰并撤离。
- **猎人与猎物**：识别并击沉两艘敌方攻击潜艇。
- **深渊穿越**：通过三处航路点，敌方锁定保持低于 85%。

## 系统

- 程序化 3D 潜艇、舰艇、海床、波浪、悬浮粒子、鱼雷与爆炸效果；跟随镜头、拖动环绕、滚轮缩放、潜望镜。
- 被动监听随自身噪声与距离变化；主动脉冲提高解算，同时泄露位置。失联接触显示最后已知位置。
- 航速、静默模式、180 米温跃层共同影响隐蔽；敌舰根据最近探测位置搜索并发射反潜鱼雷或深水炸弹。
- 制导鱼雷、装填冷却、声学诱饵、艇体损伤与紧急修复；氧气、电力和安全潜深管理。
- 战术海图点击设定航向，声呐接触点击锁定；暂停、1×/2×/4× 时间、任务结算、航行日志、音效、本机存档。
- 本机存档和最高得分保存在浏览器存储，不上传玩家数据。
- 只读 WebMCP 工具 `read_patrol_status`，返回当前任务与已知接触，不泄露未发现目标。

## 操作

| 按键 | 操作 |
| --- | --- |
| Enter | 启动巡航 |
| W / S | 加速 / 减速 |
| A / D | 左转 / 右转 |
| Q / E | 上浮 / 下潜 |
| Space | 主动声呐 |
| F / G | 发射鱼雷 / 释放诱饵 |
| C / P | 静默航行 / 暂停 |
| M | 切换战术海图 |
| 1 / 2 / 3 | 选择接触 |

## 验证

```bash
npm run check
npm test
```

核心自动检查覆盖航向坐标、暂停、静默限制、声呐、射击门槛、制导命中、撤离、任务通关、弹药耗尽、诱饵、跨层隐蔽、损管和存档恢复。浏览器操作验证覆盖启动、探测、选择、发射、视图、存档和移动布局。

`dist/` 是可独立部署的静态网站。游戏参数用于娱乐体验，不代表真实潜艇作战模型。
