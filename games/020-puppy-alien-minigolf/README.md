# 星际汪汪高尔夫 · Cosmic Pup

可直接在浏览器玩的 3D 迷你高尔夫游戏。小狗宇航员麻薯将在六座漂浮星球球场挑战 18 标准杆、18 颗星星和六种成就。

## 运行

需要 Node.js 18 或更高版本，无需安装依赖。

```sh
npm start
```

打开终端显示的本地地址。端口被占用时可运行 `PORT=5184 npm start`。部署文件全部位于 `dist/`，可由任意静态服务器托管。Three.js 已随项目保存，游戏本体不依赖外部 CDN；字体可离线回退到系统字体。

## 操作

- 鼠标指向目标；按住空格蓄力、松开击球。
- 在球场向后拖动蓄力，松手击球。
- 手机轻点球场瞄准，调节力度后点击「挥杆」。
- A / D 或左右方向键微调；C 切换俯视；R 重新挑战。
- 推杆适合地面控制，高抛可以越过低墙和裂隙。
- 每洞可以免费撤销一次；越界或进入裂隙罚一杆并返回上次击球点。
- 地图自由选关。每洞最佳杆数、最多星星、挑战完成情况保存在当前浏览器 localStorage 中。

## 关卡

1. 初次着陆：基础瞄准与力度。
2. 月牙绕行：障碍反弹与高抛捷径。
3. 奶酪沙海：沙地减速与路线选择。
4. 虫洞快递：双向传送与高墙。
5. 彗星冲刺：加速带、弹跳垫与沙地刹车。
6. 星环守门员：移动障碍、微风与危险裂隙。

## 验证

```sh
npm run check
npm test
```

物理测试覆盖：首洞一杆进洞、墙体反弹、高抛、虫洞、加速、弹跳、裂隙、沙地减速、弹跳垫停球回归、六关击球均可收敛。

使用 WebGL 2；不支持的浏览器会显示提示。音效由 Web Audio 合成，默认关闭，点击右上角音符开启。没有远程排行榜或账号系统。
