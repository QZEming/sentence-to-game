# 山谷调度局 · Valley Rail Dispatch

一个可直接运行的中文 3D 铁路调度游戏。原生 ES Modules + 本地 Three.js，无需构建或安装依赖。

## 本地运行

```sh
cd rail-dispatch
python3 -m http.server 4173 -d dist
```

打开 http://localhost:4173 。需要支持 WebGL 的现代浏览器。

## 玩法

- 5 分钟一班，14 趟客货列车，标准、高峰、夜间三种模式。
- 选择列车，设置入口道岔，开放进站信号。
- 相向列车进入不同股道完成会车。单线、股道预留和道岔由联锁保护。
- 装卸完成后对齐出口道岔，再放行。1、2 股道供客货使用；3 股道仅货运且装卸更快。
- 准点交付、完成合同赚取收入；升级装卸效率、自动出站和收入加成。
- 雨天减速、晚点扣奖、安全评分、值班报告、本机最佳成绩。
- 可旋转、缩放、俯视、点击列车；音效可选。离开页面自动暂停。

键盘：空格暂停，1/2/3 设置选中列车的进路，Enter 开放信号，R 复位视角。

## 验证

```sh
node --test tests/engine.test.mjs
```

覆盖互斥占用、道岔锁定、装卸、相向冲突、车尾释放、暂停、客货股道限制、队列、终局、奖励幂等与全班次可完成性。WebMCP 支持时可读取状态、开始值班、设置道岔与开放信号；界面与工具调用同一规则引擎。

本机最佳成绩仅存储于浏览器 localStorage。没有账号、排行榜或远程游戏存档。站点由 Sites 私有托管。

## 文件

- `dist/engine.js`：独立调度规则引擎。
- `dist/scene.js`：三维地形、铁路、桥梁、场站与列车。
- `dist/app.js`：交互、状态面板、辅助接口。
- `dist/style.css`：桌面与移动端界面。
- `dist/vendor/`：Three.js 0.170.0 和 OrbitControls，MIT 许可。
