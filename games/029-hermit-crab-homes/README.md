# 寄居日记 · Shellbound

一个完整的浏览器 3D 寄居蟹海岛小游戏。Three.js 0.180.0 已本地打包，不需要安装依赖或构建。

## 本地运行

在本目录运行 `python3 -m http.server 4377 --directory dist`，然后访问 `http://localhost:4377`。

## 操作

- WASD / 方向键：移动；点击沙滩也可移动。
- E / 屏幕上的互动提示：查看贝壳、交谈、在小屋休息。
- 空格：按住冲刺；Shift：按住躲进壳中。
- J：贝壳图鉴；Esc：暂停或关闭弹窗。
- 手机和平板：摇杆、冲刺、躲藏、互动按钮。

## 内容

- 真实 Three.js 3D 海岛、动画寄居蟹、软阴影、海水着色器、动态海浪与棕榈。
- 四个区域：暖沙海岸、岩石湾、椰影林地、珊瑚浅滩。
- 五种家：小小螺壳、桃桃扇贝、青瓷海螺、紫棘城堡、日光皇冠。
- 换壳比较速度、伤害减免和抗浪能力；旧壳留在原地，并随存档恢复。
- 四阶段主线：首次换壳、找到珍珠、集齐三颗珍珠、返回小屋点灯。
- 海鸥预警与俯冲、巡逻沙蟹、藏壳防御、棘壳反制、90 秒潮汐循环。
- 体力与冲刺、食物采集、休息回血、失败回家保留成果。
- 小地图、区域发现、贝壳图鉴、足迹与探索统计、合成音效。
- 本浏览器 localStorage 自动保存；通关后继续自由探索；支持确认后重新开始。

## 验证

已通过 JavaScript 语法检查，并在 Chrome 中通过实际输入验证了换壳、三颗珍珠收集、返巢结局、通关存档恢复、重新开始、390×844 触屏摇杆与互动。844×390 横屏无水平溢出且游戏高度适配视口。最终加载无浏览器错误/警告。

本地证据保存在被 Git 忽略的 `output/playwright/`，包含桌面、手机版、横屏、换壳和通关截图。

可选的只读 WebMCP 工具 `read_shellbound_adventure` 在支持 `document.modelContext` 的浏览器中注册；当前测试浏览器不支持该接口，因此未做 WebMCP 实机验证。它不影响普通游戏操作。

## 文件

- `dist/index.html`：入口与 UI。
- `dist/style.css`：桌面、手机和平板布局。
- `dist/game.js`：3D 场景、玩法、音效、存档。
- `dist/vendor/`：Three.js 运行库与 MIT 许可证。

进度只保存在当前浏览器，不含云存档或多人联机。需要支持 WebGL 的现代浏览器。
