# 寻壳记 · Shellbound

一个使用 Three.js 实现的低多边形 3D 寄居蟹海岛生存探索游戏。所有游戏资产均由三维几何体实时绘制，Three.js 随应用分发。

## 本地运行

在本目录运行 `python3 -m http.server 8000 --directory dist`，访问 http://localhost:8000 。

## 玩法

- WASD / 方向键移动；Shift 疾行；空格缩壳；E 互动；Q 声呐；Esc 暂停。
- 6 种贝壳具有不同容量、防御、移动速度；稀有壳需要珍珠。
- 收集海藻恢复状态，每 5 株提升体型；不合身的壳降低移动速度。
- 海鸥每轮俯冲前提供预警，缩壳可以完全防御。
- 潮汐变化会淹没外侧海滩；退到岛中央可避险。
- 与椰林邻居交谈获得线索和珍珠，成年后寻找黄金鹦鹉螺。
- 地图、贝壳图鉴、任务日志、音效开关、触屏操作和本机自动存档。
- 生命耗尽后复活，保留成长和贝壳，损失 1 珍珠。

存档保存在浏览器 localStorage `shellbound-v1` 中。部署为默认私有站点。
