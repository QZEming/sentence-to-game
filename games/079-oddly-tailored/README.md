# 异想裁缝铺 · Oddly Tailored

浏览器 3D 服装设计游戏，纯静态站点。打开已发布链接即可游玩；本地运行：

```sh
python3 -m http.server 4318 --bind 127.0.0.1 --directory dist
```

访问 http://127.0.0.1:4318 。请通过 HTTP 服务访问，不能直接以 file:// 打开 ES module。

## 玩法

- 六份订单、四种体型：梨形、四臂、长颈、圆团。
- 点击三处量体标记，选择面料、颜色、花纹和衣服款式。
- 裁片宽度目标为腹围的一半；长度为量体衣长。按顺序点击或拖过纸样节点完成裁剪。
- 缝合时在绿色区域点击落针或按空格，完成 8 针。
- 交付评分：设计 30%、合身 30%、裁剪 20%、缝合 20%。85 分三星，65 分二星。每单奖励 80 + 总评分金币。
- 金币可购买软尺、剪刀和银针升级。每单完成解锁下一位客人，并将作品保存到作品集。
- 支持鼠标和触屏旋转、滚轮和按钮缩放、双击打招呼。音效默认关闭。
- 小游戏可以重试或协助完成；协助工艺分为 65 分，不阻塞推进。
- 当前订单、金币、工具及作品均自动保存到当前浏览器 localStorage，无服务器账户或跨设备同步。

## 实现

- Three.js 0.170.0 本地模块（MIT）：`dist/assets/three.module.min.js`。
- 真正的 WebGL 网格角色、体型自适应旋转体衣服、灯光、阴影、实时布料纹理与动画。
- 生成的雏菊棉布纹理：`dist/assets/daisy-fabric.png`。
- `dist/app.js` 管理游戏状态和小游戏；`dist/style.css` 包含桌面/手机响应式布局。
- 可选 WebMCP 在支持 `document.modelContext` 的浏览器注册读取订单和调整设计工具；不支持时不影响游戏。
