# ORBITAL · 空间站维修模拟

一个中文 3D 太空站维修游戏，使用 Three.js 与 Vite。所有空间站设备、机器人和环境均由程序建模，无需外部模型素材。

## 启动

```sh
npm install
npm run dev
```

打开终端输出的本地地址。生产构建运行 `npm run build`，预览运行 `npm run preview`。

## 玩法

- 点击任务清单或 3D 设备标记：自动经中央通道前往目标。
- WASD / 方向键：手动移动；点击甲板也可设置目的地。
- Q：全域扫描，诊断范围内的设备，消耗电量。
- E：接近设备后诊断，再次交互进入维修终端。
- R：返回补给站，免费恢复电量并补满零件。
- ESC：关闭窗口或暂停任务。

维修挑战包括配电接线顺序、冷却阀门压力调节、气密焊接时机、通讯频率序列与导航核心重启。恢复四个基础系统后解锁导航核心，全部修复即可通关。完整度持续下降至零则任务失败。电量耗尽仍可应急低速移动。

每项维修奖励 120 XP；工坊中可花费 240 XP 升级移动速度和能效。地图提供导航，日志记录系统事件，支持音效、视角旋转、缩放、暂停和本地自动存档。弹窗打开时任务计时和损耗暂停。

## 交付与验证

- `src/main.js`：3D 建模、交互与游戏逻辑。
- `src/style.css`：响应式控制台界面。
- `output/playwright/`：浏览器验证脚本和截图。
- 存档保存在浏览器 localStorage 中；日志中的「重置任务存档」可重新开始。

需要支持 WebGL 的现代浏览器。字体有本地系统字体回退，游戏本身不依赖在线服务。
