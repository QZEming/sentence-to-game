# 钳王争霸 · Crab Clash

一个可直接在浏览器运行的 3D 海滩螃蟹相扑游戏。Three.js 图形库随项目提供，游戏逻辑无外部服务依赖。

## 本地运行

```sh
python3 -m http.server 5317 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:5317 。不要直接以 file:// 打开 ES 模块。

## 操作与玩法

- WASD / 方向键：按画面方向移动
- J：钳击，积累对手受击系数
- 空格：冲刺，消耗 27 耐力
- K / Shift：按住防御，保护正面；耐力耗尽会破防
- E：怒气满后释放潮汐巨钳
- Esc：暂停；M：切换声音
- 手机：虚拟摇杆与四个技能按钮

伤害增加受击时的击退力度，越过沙圈即出局。冠军之路有五轮、三次机会和回合强化；潮汐乱斗有不断缩小的擂台和连续敌人波次；自由练习提供不会主动进攻的无限陪练。海星补给恢复耐力和怒气并降低伤害。本机保存最佳击退数。

## 实现

固定 120 Hz 的圆形刚体近似：加速度、摩擦、质量、碰撞分离、冲量、方向防御、硬直和反冲。场景与角色由实时 3D 几何构建，包含动态阴影、螃蟹步态、钳击动画、粒子、潮汐、海风和合成音效。无需账户或后端数据服务。
