# 蚁境 FORMICA · 地下王国

浏览器中的单人 3D 蚁群资源管理游戏。无需构建，Three.js 已随项目打包。

## 本地运行

```sh
npm start
```

打开 http://localhost:4173 。若端口被占用，可使用 `python3 -m http.server 0 --directory dist` 并打开输出的端口。

## 玩法

- 拖动旋转 3D 巢穴、滚轮缩放；点击巢室升级，最高 3 级。
- 分配采集、挖掘、育幼与守卫；只有待命工蚁可以被分配或派出探索。
- 建设育幼室、储粮室、菌圃、蓄水室、兵蚁营、进化室；最多 12 座巢室。
- 蚁后孵化工蚁，扩建育幼室提高人口上限。
- 3 条探索路线、4 项永久进化、4 个可领取奖励的成长目标。
- 昼夜交替、雨水和甲虫事件、资源消耗与蚁后健康；健康归零会结束游戏。
- 空格暂停；数字 1、2、4 调整速度；帮助中可重新开始。
- 自动存档仅保存在当前浏览器，页面隐藏或关闭时模拟停止。

## 验证

```sh
npm test
npm run check
```

纯逻辑测试覆盖工蚁数量守恒、资源边界、扩建、孵化容量、探索返航、进化限制、事件处理、死亡状态、速度暂停、存档验证和奖励防重复领取。

## 文件

- `dist/engine.js`：独立模拟引擎
- `dist/scene.js`：Three.js 地层剖面、巢室、蚂蚁动画与相机
- `dist/app.js`：中文交互、存档、可选浏览器 WebMCP
- `dist/style.css`：响应式界面

3D 画面需要 WebGL；不支持时保留管理界面并提示开启硬件加速。字体有系统字体回退，无字体网络时仍可使用。
