# 小小仓鼠 · 巨型厨房

可直接玩的 Three.js 3D 推箱子游戏。九个手工设计、验证可解的关卡，逐步引入冰面滑行、压力踏板与栅栏，以及需要箱子互相配合的组合谜题。

## 本地运行

在本目录运行：

```sh
python3 -m http.server 4289 --directory dist
```

浏览器访问 `http://localhost:4289`。Three.js 已随代码提供，不需要安装 npm 依赖。字体加载失败时自动使用系统字体。需要支持 WebGL 的现代浏览器。

## 操作

- WASD / 方向键：移动和推箱
- Z：无限撤销（包含箱子、机关和瓜子状态）
- R：重开当前关卡
- H：根据当前局面计算下一步提示
- C：俯视 / 3D 视角
- 拖动、滚轮、缩放按钮：调整观察位置
- 点击相邻格，或使用手机方向按钮

所有关卡可自由选择。通关成绩、最佳星级、瓜子记录、成就和音效偏好保存在当前浏览器；六关通关后仓鼠会戴上厨师帽。无需账户、后端或外部服务。

## 验证

```sh
node tests/verify.mjs
```

九关参考解和实时提示均逐步重放验证；浏览器验证覆盖所有关卡完成、全部瓜子、胜利界面、成就存档、键盘移动及撤销，并检查桌面和手机布局。WebMCP 为渐进增强功能；不支持该接口的浏览器照常游玩。

## 文件

- `dist/engine.mjs`：无渲染依赖的规则、死角识别和提示搜索
- `dist/levels.json`：九关地图与参考解
- `dist/scene.js`：巨型厨房、仓鼠、棋盘和3D反馈
- `dist/game.js`：交互、音效、收集、星级、撤销和本机存档
- `dist/style.css`：桌面与手机界面
