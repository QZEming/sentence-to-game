你是一位穿行梦境的旅人。让房间的光路相连，找回遗失的记忆，抵达金色出口。

01 / 观察与旋转

点击任意房间，再按 Q / E 或旋转按钮。相邻房间的光路对接后，桥梁会亮起。

02 / 沿光前行

双击房间或点击「前往房间」，旅人会沿已连接的路径移动，并自动拾取沿途碎片。

03 / 双相梦境

第二章起按 F 切换相位。虚影房间仅在月影世界可通行。金色钥匙可以解除出口封印。

04 / 重构与传送

第三章按 X，再点击相邻房间交换位置；房间中的物品和旅人随房间移动。在紫色门上可传送。
