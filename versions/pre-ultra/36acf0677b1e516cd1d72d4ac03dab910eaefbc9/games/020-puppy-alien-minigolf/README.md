# Cosmic Pup · 星际小狗高尔夫

使用 Three.js 的完整 3D 浏览器游戏，中文界面，无需安装依赖。

## 运行

在本目录执行 `npm start`，打开 http://127.0.0.1:4173 。需要 Node.js 18+ 和支持 WebGL 的浏览器。也可用任意静态 HTTP 服务器托管 `dist`；请勿直接通过 file:// 打开 ES 模块。

## 操作

移动鼠标瞄准，力度滑块控制力度，空格或按钮击球。也可从球的位置向后拖动后松开；支持触屏。方向键左右微调瞄准、上下调整力度。R 重打当前洞，H 打开帮助。支持三个相机视角、暂停、音效开关和自由选关。

## 玩法

六座浮空球场：薄荷星初见、水晶回声谷、虫洞快递站、月球慢动作、旋转星际港、银河最后一杆。包含边界及挡板反弹、虫洞、低重力滑行、月尘减速区、动态旋转障碍、18 颗星星、球洞成绩与本设备最佳成绩、小狗跟随动画、入洞彩纸和合成音效。

## 验证

`npm test` 检查六关初始化、击球状态、运动停止、边界范围、反弹、记分，以及浏览器代理接口有效和无效参数处理。检查使用真实 Three.js 几何和模拟 DOM/渲染器，不替代浏览器视觉检查。
