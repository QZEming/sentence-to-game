# 熊与奇鱼

温暖低多边形风格的 Three.js 3D 钓鱼小游戏。

## 启动

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 54117
```

打开终端显示的地址。生产构建：`npm run build`。

## 玩法

- 按住空格或底部按钮蓄力，松开抛竿。绿色力度区间为完美抛竿。
- 浮漂下沉时按空格或点击提竿。
- 收线时按住增加张力、松开降低张力，保持绿色区域直到进度填满。
- 收集 12 种常见、稀有和传说奇鱼，在鱼篓出售收获赚取叶币。
- 森林小铺可升级鱼竿、永久解锁莓果与星尘鱼饵。
- 地图切换 3 个钓点，右上角切换昼夜，两者会影响奇鱼概率。
- 完成小心愿获取额外叶币，浏览器自动保存收集与升级进度。
- 快捷键：空格钓鱼、M 地图、B 鱼篓、Esc 关闭面板。

场景由程序化几何构建，无外部图片依赖；字体加载失败时自动使用系统字体。
