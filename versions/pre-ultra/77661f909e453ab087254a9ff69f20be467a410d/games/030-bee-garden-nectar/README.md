# 蜜野 · Honey Meadow

一个基于 Three.js + Vite 的中文 3D 花园采蜜游戏。全部场景通过程序生成，无需图片、模型或外部素材服务。

## 运行

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:5198 。生产构建：`npm run build`，输出到 `dist/`。

## 玩法

- **WASD / 方向键**：飞行；**Shift**：消耗能量冲刺；**Space**：升高。
- **E**：靠近花朵采蜜，靠近蜂巢酿蜜。长按可连续采集附近花朵。
- **H**：显示回巢方向；滚轮缩放；**Esc** 暂停。
- 手机上使用屏幕方向键与采蜜按钮。
- 130 朵可再生花朵，四种花蜜产量；花朵采后 24 秒重新开放。
- 蜜囊容量限制，回蜂巢将花蜜转为蜂蜜并恢复能量。
- 花园手记：首次采集、蜂巢交付、四种花收藏，自动发放奖励。
- 蜂巢工坊：5 级蜜囊升级、4 级翅膀升级；采蜜等级随酿蜜总量成长。
- 晴雨循环、雨滴效果、晴天增产、雨天减速、蝴蝶与其他蜜蜂。
- 实时小地图、目标花朵标记、满载返航指引、可切换合成音效。
- 使用 localStorage 自动保存资源、任务、等级与升级。位置和每朵花的冷却不存档。

## 验证

开发服务器启动后，运行 `npm test`。需要本机安装 Google Chrome。

浏览器烟雾验证通过真实键盘操作覆盖：采满 30 花蜜、任务奖励、回巢酿蜜、购买升级、刷新恢复存档、暂停与继续、帮助窗口和手机布局。截图输出至 `output/playwright/`。

`GAME_URL` 可指定测试服务器地址。存档只存在用户本地浏览器，不需要登录或后端。
