# 午夜钟楼 · 小幽灵逃脱

一个基于 Three.js 的完整 3D 解谜逃脱小游戏。所有场景、角色与道具均由几何体实时渲染。Three.js 已随项目附带，游戏不依赖 CDN；可选的 Google 字体无法加载时会自动使用系统字体。

## 运行

在项目目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:8765 。必须通过 HTTP 打开，不能直接双击 HTML（浏览器模块加载限制）。需要支持 WebGL 的现代浏览器。

## 玩法

- WASD / 方向键沿画面方向移动；也可以点击地面。
- E 与附近机关互动，也可以点击画面下方的互动按钮。
- 按住 SPACE 使用幽灵穿梭，穿过蓝色栅栏并躲避守卫；消耗灵力，松开后恢复。
- Q 开启 5 秒灵视，突出显示未收集道具，消耗 20 灵力。
- 触碰守卫会回到入口，保留所有收集物。
- 收集 3 枚齿轮、修复机芯、校准古钟、奏响三音钟，最后穿过月光之门。
- 8 枚可选记忆碎片解锁「完美归途」结局。
- 自动保存进度到本浏览器，可继续上次探索；支持暂停、静音、提示和触屏方向键。

## 解谜答案

中央古钟右侧安装三枚齿轮 → 古钟 03:15 → 铜钟 低、高、中 → 东北角出口。

## 文件

- `dist/index.html`：游戏界面
- `dist/style.css`：响应式界面样式
- `dist/game.js`：场景、输入、碰撞、机关、存档、声音、结局
- `dist/three.module.js`：Three.js 0.169.0（MIT）
- `verify.mjs`：无渲染器的机关链路回归检查，运行 `node verify.mjs`
