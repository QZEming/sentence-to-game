# 深土之下 · Underburrow

Three.js 原创 3D 鼹鼠地下迷宫游戏。无需后端与外部美术资源，所有模型均由程序生成。

## 运行

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5186
```

浏览器打开 http://127.0.0.1:5186 。`npm run build` 生成 `dist/`，`npm run preview` 预览生产构建；`npm test` 验证 200 个随机种子的迷宫连通性、出口可达性及边界。

## 玩法

- WASD / 方向键移动，Shift 冲刺，E 挖掘面前棕色软土。
- Q 声呐消耗 20 体力，地图显影 7 秒、甲虫眩晕 5 秒，冷却 18 秒。
- 收集每层全部 3 枚月光水晶，前往右下角金色升降梯进入下一层。
- 收集蘑菇币升级利爪；紫色营地蘑菇恢复 30 生命并补满体力，每株只能使用一次。
- 甲虫会巡逻并在接近时追击；受伤后短暂无敌。生命耗尽可重新开始。
- 体力自动恢复，层数递增时迷宫重新生成、敌人增加、生命与体力补满。
- 鼠标拖动旋转，滚轮或按钮缩放；P / 空格暂停；手机可用屏幕按钮。
- 每次移动、收集、挖掘、升级自动保存。刷新后点“继续探险”。保存于当前浏览器当前站点，不跨设备同步。

## 实现

- `src/main.js`：3D 模型、灯光、游戏循环、交互、敌人、粒子、音效和存档。
- `src/maze.js`：带种子的迷宫生成器。
- `src/style.css`：响应式界面。
- `tests/maze.test.js`：地图生成性质验证。

需支持 WebGL 的现代浏览器。界面字体有在线增强，网络不可用时自动回退系统字体；游戏资源由本地依赖打包提供。
