# 鲸落秘境 · WHALEFALL

一个以蓝鲸探索沉没文明为主题的 Three.js 3D 游戏。全部场景、鲸鱼、遗迹、珊瑚、鱼群、水母与粒子均为程序生成，无需下载模型或贴图。

## 启动

```bash
npm install
npm run dev -- --port 5173
```

打开 http://localhost:5173 。生产构建：`npm run build`；预览构建：`npm run preview`。需要支持 WebGL 2 的现代浏览器，建议开启硬件加速。中文字体使用系统回退，因此离线仍可游玩。

## 航程

1. 靠近并收集 6 枚金色记忆碎片。
2. 前往 3 座青色共鸣祭坛，靠近后按 E 唤醒。
3. 回到中央神殿，靠近归海之门并按 E 完成航程。
4. 通关后可继续自由探索，阅读完整的四篇探索日志。

## 操作

| 按键 | 操作 |
| --- | --- |
| W / S，↑ / ↓ | 前进 / 后退 |
| A / D，← / → | 左转 / 右转 |
| Space / C 或左 Ctrl | 上浮 / 下潜 |
| Shift | 冲刺，消耗能量 |
| Q | 鲸歌声呐，冷却 10 秒，安抚 55 米内水母 9 秒 |
| E | 唤醒祭坛 / 穿越光门 |
| M / J | 海图 / 日志 |
| Esc | 暂停 / 继续 |
| 拖动鼠标 | 环视，松开后视角逐渐复位 |

触屏设备显示方向、升降与交互按钮。底部能力按钮同样可点击。

## 机制

- 冲刺消耗能量，普通游动时恢复。
- 水母接触造成伤害，短暂无敌防止连续伤害。
- 青色浮游生物恢复生命和能量，采集后会重新生长。
- 生命耗尽由洋流送回入口，保留任务进度。
- 小地图实时定位，海图可点击设置自定义航标。
- 本地自动存档每 5 秒保存，收集、激活、暂停和离开也会保存。
- 可开关合成海洋音效，默认静音。
- 切换标签页或窗口失焦时自动暂停。

## 技术

原生 JavaScript、Three.js、Vite。后处理辉光、距离雾、动态海洋粒子、光束与程序生成几何。源文件：`src/world.js` 为场景，`src/main.js` 为玩法和 UI，`src/style.css` 为界面。
